# 术语表（交付里统一用左列；项目旧文件里的旧称照读）

适用于总表、场次表、pitch、批注、改稿单。剧本正文的台词与动作描写不适用，照 SKILL.md §4 写成人话。0.10.0 起处境卡、方向卡、节拍单、台账、框架卡、规则表、决策记录、约束文件都不再是文件，它们的内容在总表的节里；旧称列出来是为了读旧项目。

| 术语 | 含义 | 旧称（旧文件里可能出现） |
|---|---|---|
| 交付写法 | SKILL.md §1：正文只写故事、过程不进正文；结论先行；一条一事；一格一句；一处一写；写明状态；版本记录一版一行；pitch 是唯一允许短散文的交付 | 交付文字 |
| 过程 | 谁哪天说了什么、哪版加的删的、被否的候选、原话、理由；只在文末版本记录和 git，正文只留指针 | 工作日志、版本说明、决策记录 |
| 总表 | 一部剧故事层唯一的档（`story/<剧名>.md`，模板 `templates/project.md`）：1 这部剧 · 2 主要人物 · 3 季线 · 4 正典与悬线 · 5 制作参数 · 6 不走的路 · 7 各集 · 版本记录 | 台账、账本、框架卡、规则表、决策记录、约束文件、处境卡、方向卡、节拍单 |
| 燃料 / 围栏 | 总表前四节是生成的燃料，第 5 节制作参数是围栏；按顺序读，成本最后算 | — |
| 这部剧怎么写 | 总表第 1 节 ≤ 6 句：本剧自己的写法，写目的不写禁令，不编号；从用户的纠正里来；判断按目的推 | 本剧规则表、R#、已定规则、硬约束、记忆里的偏好 |
| 通用默认 | 三测、脚本阈值、四种对白失误、按故障改稿表与"成立"表、题材手册；本剧另有写法或这场处境需要时让位 | — |
| 规则之外 | 第 1 节没管到的新写法：不算问题，需要时标出给用户看 | — |
| 中心论点 / 反论点 | 这部剧在争论的一句可争论的话；主角开场实际按着过日子的那句（第 1 节） | 主题、核心戏剧问题 |
| 调性 | 是什么样的故事、不是什么样的故事（第 1 节） | 调性边界 |
| 主要人物 | 总表第 2 节每人 ≤ 6 行：要什么、怕什么、手里有什么、这一季的弧或计划、现在在哪、说话的做法 | 人物当前状态、人物此刻、台账 D 节、信念弧 |
| 这一季的弧 | 主角开场怎样行动 → 季末怎样行动；写行动不写性格 | 信念弧、人物弧光 |
| 外部力量与计划 | 有计划的人、机构、日程：这一季要做成什么、下一步是什么、哪集和谁相撞（第 2 节人物行、第 3 节相撞表）；主线事件的来源 | 引擎、周围的人 |
| 说话的做法 | 从已采用台词取证的声音：先注意什么、怎样提要求 / 拒绝 / 开玩笑（第 2 节） | 声线依据、台账 G 节 |
| 季线 | 总表第 3 节：季终落点、中点一次、支柱集、外部力量与相撞、每集一行；先在对话里 pitch，定了才写 | 季卡、故事框架卡、季的形状、骨架 |
| 季终落点 | 本季最后落下的事件或画面，不是主题句；AI 给候选，用户定 | 季末那一下 |
| 支柱集 | 第一次代价 / 中季转向 / 倒数第二 / 季终，各一句落点；只写落点不写手段 | tentpole、关键集 |
| 中点一次 | 主角第一次按论点行动、随即付代价的那一下在哪集 | — |
| 每集一行 | 第 3 节的表：集 / 一句话（A 线；B 线或跑线）/ 对论点的位置 / 代价落在谁身上 / 状态 | 每集一句话、分集一览 |
| A 线 / B 线 / 跑线 | 一集里的主线、副线、贯穿的轻线（A / B / C story、runner） | 主线 / 副线 |
| 对论点的位置 | 一集或一个候选让主角离论点更近、更远，还是反讽地看似更近实则更远；"不动"要写明 | 和季的关系 |
| 口味探询 | 季线或候选 pitch 之前的一条消息，三到五问：多大的事、谁施压、季终画面、绝不要什么、哪一场最像这部剧 | — |
| pitch | 在对话里给用户反应的完整候选：季线每条 ≤ 15 行、本集候选每条 ≤ 10 行，短散文，不用表、不算成本；选定了才进总表 | 方向卡、候选卡 |
| 规模门 | 本集候选必答的三项：主线事件是什么新东西、要几集演完；碰到名利场 / 事业 / 私生活 / 两人关系的哪几层（≥ 2）；谁在推、是他计划的哪一步。三条里最多一条是上一集的局部后果 | — |
| 主线事件 | 进入世界后要几集才演完的新东西；只够一集的是后果，不是事件 | 核心事件 |
| 实质差异检查 | 任意两个候选在选择 / 代价 / 后果里至少两项不同；AI 自做，用户问才摆出来 | — |
| 关系起点 → 终点 | 每个候选一行：这条线让两人的关系与处境从哪里到哪里 | 关系与处境 |
| 不走的路 | 总表第 6 节 ≤ 10 行：被否的季线和方向，名字 + 三个字的原因；防止再被提出来 | 决策记录的否决行 |
| 要定的一件事 | 第 7 节每集首行：这一集一句话怎样成立里最卡的一项 | 核心待决问题、真正要定的一件事、处境卡 |
| 讨论落稿 | 把讨论记录分成已决定 / 备选 / 未决 / 待核实，每条一行写内容；在对话里，点头的进第 7 节（`story-development.md` §1） | — |
| 事件链 | 第 7 节：选定候选的 ≤ 6 拍，标因果 / 转折 | 节拍表、方向卡的事件链 |
| 拍间关系 | 因果（由上一拍直接导致）/ 转折（上一拍的结果被阻断或逆转） | 连接词、因此 / 但是 |
| 戏化 | 把事件链里的一件事变成一场戏：在场者与形式、进出的时刻、价值转向、观众知情（`dramatization.md`） | 展开、写成戏 |
| 三问 | 每场一格：谁要什么 / 得不到会怎样 / 为什么是现在；答不出的不是戏（Mamet） | — |
| 开场值 → 结束值 / 转折拍 | 一场里一个价值从哪到哪；转向发生的那一拍；场末回到开场值 = 没转向（McKee） | 这场有没有变化 |
| 余韵场 | 没有转向、作用在集的层面的场；场次表里写明作用 | 过场、氛围戏 |
| 在场者与形式 | 一件事由谁在谁面前、以当面 / 电话 / 转述 / 看见中的哪种方式发生；选让主角当场必须回应的那种 | 谁在场 |
| 变化轴 | 变化落在内在 / 人际 / 外部哪一轴（Mazin）；连续只动外部轴 = 人物在办事不在经历 | — |
| 进晚出早 | 从冲突已在场的一刻进，转向落定后尽快出 | — |
| 切点 | 短集里一场或一集结束、下一段从哪一句或哪个动作接 | 断点、卡点 |
| 场次表 | 第 7 节每集一张，一场一行：场景 · 在场者与形式 / 三问 / 开场值 → 结束值 / 本场改变了什么 / 成本 / 状态；确认后不重编场号 | 节拍单、分场 |
| 本场改变了什么 | 场次表的一栏和场景头部的一行（键名保留）：删去本场，观众会缺失的信息或情感 | — |
| 成本 | 场次表的一栏，只在这一步算：新景 / 新人物 / 同框 / 台词秒数；数字按第 5 节 | 可拍性预检、制作成本、制作提示 |
| 结尾钩子 | 由本集产生、留给下一集的悬念，只从本集已发生的事产生 | 牵引 |
| 正典与悬线 | 总表第 4 节：已拍的集每集 2–3 行、悬线表、活着的秘密 | 台账 A / B / C / F 节 |
| 悬线 | 已埋、未回收的事件、承诺、把柄或亏欠：谁握着什么、能引出的选择、状态 | 伏笔、债 |
| 回收 | 悬线在后续剧情中兑现、被处理或作废；改状态不删行 | 还债、用掉 |
| 活着的秘密 | 此刻还在起作用的信息差：事 / 谁知道谁不知道 / 观众知情、误信或在等什么 | 信息分布、信息差、台账 B 节 |
| 误信 / 在等的答案 | 观众知情的两种状态：相信了一件不实的事；此刻在等哪个问题的答案 | — |
| 新事实 | 本集首次出现、待进第 4 节的事实；第 7 节一行一条，只写事实本身 | 新事实提案 |
| 未纳入 | 第 7 节：没进本集的内容与去向（下一集 / 以后 / 留白 / 不进正典） | — |
| 关键拍的成立条件 | 人物的选择难以置信的一到三拍：当时知道什么、还有什么选择、依据在哪场；可选，写在事件链之后 | — |
| 最小补写 | 后场转折缺前场铺垫时，补在哪一场、最少建立什么，补写在那一场本身也有作用 | — |
| 制作参数 | 总表第 5 节（0.9.0 前在 `story/constraints.md`）：人物、地点、禁用、必填头部、同框上限、语速与单条上限；脚本据此检查和估秒 | 约束文件 |
| 版本栏 | 场景头部首行：版本号、日期、探索 / 采用、依据的总表集与场 | — |
| 本版改动 | 改 / 删 / 加（旧句 → 新句）；0.10.0 起在对话里（改稿单）和 git，不进文件 | 改动清单 |
| 版本记录 | 总表文末和场景稿正文之后各一节，一版一行：`vN · 日期 · 改了什么`；0.9.0 前场景稿叫"历次" | 历次、改动记录、修改记录 |
| 指针 | 已写在别处的内容只留一行：见第几节 / 已被 vN 取代；不附要点和被否原因 | — |
| 改稿单 | 对话里交付的改稿结论：问题在哪层、本轮目标、定位、幅度、改法、改动、前后对照、连带影响、保留项；不落档（`templates/revision-note.md`） | — |
| 采用 / 探索 | 用户说"用这个 / 就这样 / 落档"才算采用；其余是探索稿，不进正典和生产 | — |
| 批注块 | 以"场 NN vN · 批注（日期）"为标题的批注，只在用户要审或有要标的问题时写：块头写上一版的已改 / 沿用 / 作废、结论、脚本线索，条目按处理方式分组 | 批注表 |
| 批注分组 | 要改 / 可换 / 待你定 / 保留项 / 交导演层 / 后场衔接 / 已关闭；只写用得上的组 | 逐句罗列 |
| 备选台词 | 挂在批注原句下的几种说法，用户选定后只把一句写进正文 | — |
| 锁定场号 | 场次表确认后不重编；插入的场加字母（02b），删掉或 hold 的场号不复用 | — |
| 本场任务 / 人物的当下尝试 | 写一场之前的两行：作者要这场完成什么；每个在场的人此刻想办成什么 | — |
| 进入依据 | 人物为什么来、为什么现在开口、为什么没走或没拒绝；落在前置事件、事务、关系或限制上 | — |
| 交往 / 接收 | 一次开口或举动，以及对方实际接收到的（可能听错、只抓住一个词、不回应） | — |
| 交替代入 | 写一轮交流时轮流站到说的人和听的人的位置，写出回应，再面对这个新事实往下写 | — |
| 意图 / 障碍 / 办法 | 关键来回每句之前的一行：这句在争取什么；什么挡着他直说；用的手段 | 潜台词 |
| 回应阶梯 | 一句回应可落的八级：直接答 / 延迟 / 带理由 / 答别的 / 反问 / 转第三者 / 落在动作 / 不答；不情愿的回应不直接 | 回应方式 |
| 不情愿的回应 | 拒绝、不同意、推辞、坏消息：口语里通常延迟、绕开、更长、带理由 | 拒绝 |
| 两栏草稿 | 关键来回先写"想说的 / 说出口的"两栏；左栏不进正文 | 潜台词表 |
| 结构信号 | "像写出来的"四种句子结构：等长对仗、三连排比、格言式开头、接住对方的词反问（`dialogue-patterns.md` §5） | 金句、台词感 |
| 接住上一句的词反问 | 换人后的短问句用了上一句的词再反转（脚本线索）；只是复述确认不算 | 接词反问 |
| 修改幅度 | 按故障选改到哪一层：措辞 / 交往方式 / 场内事件 / 前场（`scene-work.md` §3） | — |
| 本轮目标 | 一次改稿要解决的主要问题，一句话；写在改稿单第二行 | — |
| 前后对照 | 改稿后每处一行：断在哪 → 新稿哪一句或动作补上；另起一行写损失 | — |
| 停止条件 | 关键反应有依据、已定的作用在正文里看得见、结尾和保留项成立 | — |
| 保留项 | 上一版里承载识别性、回应关系或吸引力，改稿时不能丢的台词与动作 | 保留清单 |
| 外部反馈 | 真实读稿、排练、导演现场或成片带回的观察；记来源类型和位置，没发生的不虚构 | — |
| 表面线索 | 脚本按问号、词语重合、关键词给出的提示，不是判断 | 精准接话、疑似金句 |
| 画内 / 画外说话人 | 画外：角色名或括注写了电话里、画外、旁白、V.O. 等的说话人。同框人数看动作描写，不按说话人数算 | — |
| 题材手册 | 通用默认的题材版（`genre-playbooks/`）：引擎、先问的问题、单集形状、戏化手法、对白规范、观众知情、常见失误、形状参考；本剧用哪本写在总表第 1 节 | 类型手册 |
| 场景的游戏 | 一场喜剧戏里那个在升级的不寻常的东西：基础现实 → 第一个不寻常 → 升级与探索（UCB） | 梗、包袱 |
| 正常人 / 失常者 | 喜剧里看见荒唐并给反应的人 / 认真做荒唐事、不知道自己好笑的人 | 捧哏 / 逗哏 |
| 钟 | 赛制或日程里逼人在某一天做选择的节点；一集一个 | 时间节点、deadline |
| 信息段 | 交代赛制、名单、结果的那几秒；只放会改变谁的决定的数字，压成一个画面加一句反应 | 交代戏 |

不用的写法：口语比喻（"债""欠什么""那一下"）、口语化的列名（"谁对谁""对方怎么接"）、散文段落（pitch 除外）、同一件事在几处各写一遍（写全一处，别处留指针）、正文里的过程标注——版本号、日期、用户原话、"已删 / 作废"、"（不揭）"（进版本记录或 git）、用成本行去筛季线和方向。
