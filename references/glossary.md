# 术语表（交付里统一用左列；项目旧文件里的旧称照读）

适用于处境卡、方向卡、节拍单、场次表、批注、改稿单、决策记录。剧本正文的台词与动作描写不适用，照 SKILL.md §4 写成人话。

| 术语 | 含义 | 旧称（旧文件里可能出现） |
|---|---|---|
| 交付写法 | SKILL.md §1 的写法：结论先行；一条一事；上下文只给必需的那一点；一处一写，别处留指针；写明状态；改动记录一版一行 | 交付文字（0.3.0–0.6.0 的段名） |
| 台账 | 正典事实、信息分布、伏笔、人物当前状态与时间线的总表（`story/ledger.md`） | 账本 |
| 季卡 | 台账首节：一句话梗概、本季核心戏剧问题、调性边界、季终落点、主角核心利害、不可变更的设定 | — |
| 故事框架卡 | 季卡之后、处境卡之前的季级对象（`story/framework.md`）：中心论点、信念弧、引擎、季的形状、每集一句话、框架层待定；只写落点不写手段 | 骨架、总架构、S1 故事框架 |
| 中心论点 / 反论点 | 这部剧在争论的一句可争论的话；主角开场实际按着过日子的那句 | 主题、核心戏剧问题（季卡保留此项） |
| 信念弧 | 主角开场按什么信念行动 → 季末怎样行动；写行动不写性格 | 人物弧光、成长线 |
| 中点一次 | 季中主角第一次按论点行动、随即付代价的那一下 | — |
| 引擎 | 这部剧每集的事件从哪来：周围的人替两人做决定 / 行业与赛制日程 / 世界规则的代价 / 人物现在在哪 | 故事发动机 |
| 支柱集 | 季的形状里的几根柱子：开季 / 第一次代价 / 中季转向 / 倒数第二 / 季终；只写落点 | tentpole、关键集 |
| 每集一句话 | 框架卡第 5 节：每集 A 线一句、B 线或跑线、对论点的位置、代价落在谁身上、状态 | 分集一览、分集梗概 |
| A 线 / B 线 / 跑线 | 一集里的主线、副线、贯穿的轻线（美国电视编剧室的 A / B / C story、runner） | 主线 / 副线 |
| 对论点的位置 | 一集或一个候选让主角离论点更近、更远，还是反讽地看似更近实则更远；"不动"要写明 | 和季的关系 |
| 戏化 | 把事件链里的一件事变成一场戏：定在场者与形式、进出的时刻、价值转向、观众知情（`references/dramatization.md`） | 展开、写成戏 |
| 三问 | 每场一行：谁要什么 / 得不到会怎样 / 为什么是现在；答不出的不是戏（Mamet） | — |
| 开场值 → 结束值 / 价值转向 | 一场里一个价值（安全 / 危险、知情 / 不知情、主动权在谁……）从哪到哪；场末回到开场值 = 没转向（McKee） | 这场有没有变化 |
| 转折拍 | 转向发生的那一拍，由行动或揭示引起；一场以一次为主 | 高潮、反转 |
| 余韵场 | 没有转向、作用在集的层面的场（陪伴、观察）；三问表里写明作用 | 过场、氛围戏 |
| 在场者与形式 | 一件事由谁在谁面前、以当面 / 电话 / 转述 / 看见中的哪种方式发生；选让主角当场必须回应的那种 | 谁在场 |
| 变化轴 | 每拍变化落在内在 / 人际 / 外部哪一轴（Mazin）；连续只动外部轴 = 人物在办事不在经历 | — |
| 进晚出早 | 从冲突已在场的一刻进，转向落定后尽快出 | — |
| 切点 | 短集里一场或一集结束、下一段从哪一句或哪个动作接；可落在一句话中间 | 断点、卡点 |
| 意图 / 障碍 / 办法 | 关键来回每句之前的一行：这句在争取什么；什么挡着他直说；用的手段 | 潜台词 |
| 回应阶梯 | 一句回应可落的八级：直接答 / 延迟 / 带理由 / 答别的 / 反问 / 转第三者 / 落在动作 / 不答；不情愿的回应不直接 | 回应方式 |
| 不情愿的回应 | 拒绝、不同意、推辞、坏消息：口语里通常延迟、绕开、更长、带理由（会话分析的偏好组织） | 拒绝 |
| 两栏草稿 | 关键来回先写"想说的 / 说出口的"两栏；左栏不进正文 | 潜台词表 |
| 结构信号 | "像写出来的"四种句子结构：等长对仗、三连排比、格言式开头、接住对方的词反问（`dialogue-patterns.md` §5） | 金句、台词感 |
| 接住上一句的词反问 | 换人后的短问句用了上一句的词再反转（脚本线索）；只是复述确认不算 | 接词反问 |
| 题材手册 | 通用默认的题材版（`references/genre-playbooks/`）：引擎、先问的问题、单集形状、戏化手法、对白规范、观众知情、常见失误、形状参考；本剧规则优先 | 类型手册 |
| 场景的游戏 | 一场喜剧戏里那个在升级的不寻常的东西：基础现实 → 第一个不寻常 → 升级与探索（UCB） | 梗、包袱 |
| 正常人 / 失常者 | 喜剧里看见荒唐并给反应的人 / 认真做荒唐事、不知道自己好笑的人 | 捧哏 / 逗哏 |
| 钟 | 赛制或日程里逼人在某一天做选择的节点（考核日、名单公布、提名）；一集一个 | 时间节点、deadline |
| 信息段 | 交代赛制、名单、结果的那几秒；只放会改变谁的决定的数字，压成一个画面加一句反应 | 交代戏 |
| 调性边界 | 本剧不是什么样的故事 | 调性终点 |
| 季终落点 | 本季最后落下的事件或画面 | 季末那一下 |
| 核心利害 | 主角当前必须守住、一旦失去就会改变其选择的东西 | 此刻必须保护的东西 |
| 伏笔 | 已埋设、尚未回收的事件、承诺、把柄或人物间的亏欠；每条注明可引出的选择与最晚回收点 | 债、未兑现的设定 |
| 回收 | 伏笔在后续剧情中兑现、被处理或作废 | 还债、用掉 |
| 信息分布 / 信息差 | 某一事实各人物与观众是否知情：知情 / 不知情 / 部分知情 | 谁知道什么、知一半 |
| 人物当前状态 | 当前目标、恐惧、筹码、上集遗留、下一次交集；写处境，不写性格 | 人物此刻 |
| 目标 | 人物在本拍想得到的 | 此刻要什么 |
| 行动 / 对方反应 | 本拍人物做了什么 / 对方如何回应 | 做了什么 / 对方怎么接 |
| 处境变化 | 本拍之后谁的处境、筹码或关系变了 | 谁的条件变了 |
| 观众知情 | 观众此时已知、未知的信息（与人物的信息差） | 观众此刻知道 / 不知道 |
| 拍间关系 | 本拍与上一拍的连接：**因果**（由上一拍直接导致）/ **转折**（上一拍的结果被阻断或逆转） | 连接词、因此 / 但是 |
| 单集四问 | 前情承接 / 切入点 / 核心事件 / 结尾钩子 | 一集四问：承接 / 进入 / 兑现 / 牵引 |
| 结尾钩子 | 由本集产生、留给下一集的悬念（不另起新谜题） | 牵引 |
| 核心待决问题 | 处境卡交给用户拍板的那一项 | 真正要定的一件事 |
| 场次表 | 节拍单改定后的分场：场次、场景、对应节拍、本场改变了什么 | — |
| 本剧规则表 | 这部剧自己的写法规则（`story/rules.md`）：规则、目的、层级、出处、例子、已登记的例外、状态；写或审一场之前先读 | 已定规则、硬约束、记忆里的偏好 |
| 通用默认 | 本 skill 的三测、脚本阈值、四种对白失误、按故障改稿表与"成立"表；本剧规则另有规定或这场处境需要时让位 | — |
| 违反规则 / 已登记的例外 / 规则之外 | 判断的三类：违反要改或写理由请用户登记；已登记的例外照写；规则没管到的新写法不算问题 | — |
| 规则成文 | 一集采用后，把"这部剧该怎么写"的纠正起草成规则条目，交用户确认 | — |
| 本场改变了什么 | 场景头部的一行（键名保留，脚本按键名检查）：本场造成的变化；删去本场，观众会缺失的信息或情感 | — |
| 版本栏 | 场景头部首行：版本号、日期、依据的节拍单版本与拍号（对应修订页眉） | — |
| 本版改动 | 场景头部里相对上一版的改动：改 / 删 / 加，引用旧句与新句（对应修订标记、Track Changes） | 改动清单 |
| 历次 | 场景头部本版改动之后的一节：更早的版本一版一行，全文在版本历史 | 头部逐版写的版本说明 |
| 改动记录 / 版本记录 | 记版本变化的地方，一版一行：vN · 日期 · 改了什么 · "原话一句"。节拍单在文末"版本记录"，场景稿在头部"历次"，规则表在文末"修改记录"，skill 在 CHANGELOG | 版本说明段落 |
| 指针 | 已写在别处、或被新版本取代的内容只留一行：标题——已被 vN 取代 / 见某文件某节；全文在版本历史（git） | — |
| 批注块 | 以"场 NN vN · 批注（日期）"为标题的批注：块头写上一版批注的已改 / 沿用 / 作废、结论、脚本线索，条目按处理方式分组（对应 Scriptation 的跨版本批注） | 批注表 |
| 批注分组 | 批注条目按处理方式归组：要改 / 可换 / 待你定 / 保留项 / 交导演层 / 后场衔接 / 已关闭；只写用得上的组 | 逐句罗列 |
| 备选台词 | 挂在批注原句下的几种说法，用户选定后只把一句写进正文（对应 Final Draft 的 alternates） | — |
| 锁定场号 | 场次表确认后不重编；插入的场加字母（02b），删掉或 hold 的场号不复用 | — |
| 讨论落稿 | 把讨论记录、构思或零散意见分成已决定 / 备选 / 未决 / 待核实，每条带原话（`story-development.md` §1） | — |
| 关系与处境（起点 → 终点） | 方向卡每个候选的一行：这条线让两人的关系与处境从哪里到哪里 | — |
| 关键拍的成立条件 | 节拍单的可选项：这一拍人物当时知道什么、还有什么选择、依据在哪一场 | — |
| 误信 / 在等的答案 | 观众知情的两种状态：相信了一件不实的事；此刻在等哪个问题的答案 | — |
| 最小补写 | 后场转折缺前场铺垫时，补在哪一场、最少建立什么，补写在那一场本身也有作用 | — |
| 本场任务 / 人物的当下尝试 | 写一场之前的两行：作者要这场完成什么；每个在场的人此刻想办成什么。两者分开写 | — |
| 进入依据 | 人物为什么来、为什么现在开口、为什么没走或没拒绝；落在前置事件、事务、关系或限制上 | — |
| 交往 / 接收 | 一次开口或举动，以及对方实际接收到的（可能听错、只抓住一个词、不回应） | — |
| 交替代入 | 写一轮交流时轮流站到说的人和听的人的位置，写出回应，再面对这个新事实往下写 | — |
| 修改幅度 | 按故障选改到哪一层：措辞 / 交往方式 / 场内事件 / 前场（`scene-work.md` §3） | — |
| 本轮目标 | 一次改稿要解决的主要问题，一句话；写在本版改动的标题里 | — |
| 前后对照 | 改稿后每处一行：断在哪 → 新稿哪一句或动作补上；另起一行写损失 | — |
| 停止条件 | 关键反应有依据、已定的作用在正文里看得见、结尾和保留项成立 | — |
| 保留项 | 上一版里承载识别性、回应关系或吸引力，改稿时不能丢的台词与动作 | 保留清单 |
| 声线依据 | 台账可选的 G 节：人物对谁、在什么处境、用过哪句已采用台词、观察到的做法；暂定或已确认 | — |
| 外部反馈 | 真实读稿、排练、导演现场或成片带回的观察；记来源和位置，没发生的不虚构 | — |
| 表面线索 | 脚本按问号、词语重合、关键词给出的提示，不是判断 | 精准接话、疑似金句 |
| 画内 / 画外说话人 | 画外：角色名或括注写了电话里、画外、旁白、V.O. 等的说话人。同框人数看动作描写，不按说话人数算 | — |
| 制作参数 | 约束文件 `## 制作参数` 一节：英文语速、中文语速、单条生成上限；脚本据此估口播秒数，没配置就不估 | 写死在脚本里的 4 词/秒、30 s |

不用的写法：口语比喻（"债""欠什么""那一下"）、口语化的列名（"谁对谁""对方怎么接""挡住什么"）、"此刻"作列名或标签（改用"当前"）、散文段落、同一件事在几处各写一遍（写全一处，别处留指针）。
