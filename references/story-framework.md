# 季线：先聊出骨架，再写戏

用法：新项目、新季开工；进行中的剧总表第 3 节支柱待定两根以上；用户说"骨架""主线""这一季要去哪""先别细节"；本集候选被否时用户的话里有"没抓住""太薄""没有新的主线事件""跟主线不沾边"。写进总表第 3 节的只有定下来的；候选在对话里。模板 `templates/project.md`；案例只写短名，出处与复核状态见 `sources.md`。

## 1. 为什么先聊

季线是口味问题，不是推导问题：同一份正典能长出几条季线，哪一条对，只有用户反应了才知道。所以这一层不交卡、不填表：先问口味，再 pitch 完整的季线让用户反应，当轮改，定了才写。编剧室也这么做：季末落点和调性终点先定（Armstrong），拆季时才找手段（Hacks），每季从"人物现在在哪"问起（Breaking Bad 编剧室）；结构是症状，不是工具（Mazin）。

0.9.0 之前的框架卡只登记落点和"待定"，没有想出落点的办法；季终待定两周，每张卡都继承待定，候选自然"太薄"。这一版把登记表换成 pitch。

## 2. 口味探询（一条消息，三到五问，一次问完）

1. 这一季你想要多大的事：一件改变两人处境的大事，还是一串小事累成的变化？
2. 施压的是谁：周围的人、行业的钟、还是两人自己？哪个人物你想看他动起来？
3. 季终你能接受的画面是哪一类：两人站到一边 / 分开 / 位置对调 / 外人赢了？
4. 口味上绝不要什么（不是规则，是你不想看的）？
5. 已拍的集里，哪一场是你觉得"这部剧就该这样"的？

用户答了几个就用几个；没答的按正典推，pitch 里标"推断"。不为了问全而追问。

## 3. 一条季线的 pitch 长什么样（≤ 15 行短散文，不用表）

每条一个名字，按这个顺序写：

- **季终落点**：事件或画面一句，不是主题句。
- **三根支柱**：第一次代价 / 中季转向 / 倒数第二，各一句落点和对论点的位置（更近 / 更远 / 反讽）。开季已拍的不写。
- **外部力量与计划**：两三股有计划的力量（人、机构、日程），各自这一季要做成什么、什么时候和谁相撞。写不出计划的下一步，这股力量就撑不起主线。
- **大悬线在哪集兑现**：第 4 节里最值钱的两三条，哪集、由谁拿出来。
- **两位主角各失去什么**：一人一句。
- **中点一次**：主角第一次按论点行动、随即付代价的那一下在哪集。

两三条 pitch 之间要在"季终落点 / 谁施压 / 代价落在谁"至少两项上不同；只换地点、人名、措辞的不算。

## 4. 聊的规矩

- 一轮给两到三条，不推荐；用户问才说更倾向哪条和原因一句。
- 用户的反应当轮接住：合并两条、换季终、换施压者，就地改，不另开一轮。
- 用户给了自己的季线：写成同样的形状，再配一条对照，不替用户否定。
- 两轮之后没有一条被选中或合并 → 停，问一句"哪一条离你要的最近、差在哪"，不 pitch 第三轮。
- 每集一行排完，看两位主角之间的关系有没有推进的位置；没有就补一集关系戏，不塞进任务集（Hacks "One Day"）。
- 定了：写总表第 3 节（季终、中点、支柱、外部力量、每集一行），写不出的格留空；被否的 pitch 只在第 6 节留名字和三个字的原因。

## 5. 一行中心论点（借 Mazin，只借一行加一个检查）

- **可争论的一句**：写成有人会反对的判断。"圈子里的人情不记账就活不下去"可争论；"友情"不可争论。检查：把它反过来，反面也站得住，才算论点。
- **反论点与稳态**：主角开场按反论点活着，而且活得过得去；激励事件打破的是这个稳态。
- **季末只差一件事**：首尾两集的差别是主角按哪个信念行动，不是他说了什么。
- **用法**：每条 pitch 和每个本集候选写"对论点的位置：更近 / 更远 / 反讽 / 不动"，作差异检查的参考维；不计入两项。
- **边界**：论点不进台词。轻喜剧、群像剧论点常常弱，允许写"待发现"，但要写出目前最像的一句，三集之后回头看。

## 6. 引擎：主线事件从哪来

一季的事件从外部力量的计划来；单集的事件从计划撞上"人物现在在哪"来。

| 来源 | 一句 | 例 |
|---|---|---|
| 有计划的外人 | 一个人替两人决定了什么，而且还有下一步 | Hacks：开除、官司、敲诈都是一个人替两人决定 |
| 行业或赛制的钟 | 日程节点逼人在某一天选 | 颁奖季、考核、名单公布 |
| 世界规则的代价 | 规则讲一次，之后每次用都付代价 | 使魔离不开女巫，她去哪他们都得跟 |
| 人物现在在哪 | 从当前状态推下一步，不从悬线倒推 | Breaking Bad 编剧室每季从 "Where's Skyler at?" 问起 |

"周围的人替两人做决定"只是单集形状；写不出那个人的下一步，它撑不起一季。总表第 2 节每个外部人物的"这一季的计划"就是这一行的来源；第 1 节"怎么写"里排除的来源（如"两位主角不互害"）不能当事件。

## 7. 本集候选：规模门

季线定了之后，每集的候选仍在对话里 pitch：两到三条，每条 ≤ 10 行，每条必须答——

- **主线事件**：什么新东西进入了世界；要几集才演完。只够一集的，是后果不是事件。
- **碰到哪几层**：名利场 / 事业 / 私生活 / 两人关系，至少两层。
- **谁在推**：哪股力量的哪一步（第 2 节的计划、第 3 节的相撞表）。
- **关系起点 → 终点**；**对论点的位置**。

三条里最多一条是"上一集的局部后果"。制作成本这一步不算，选定后在场次表算。实质差异检查（选择 / 代价 / 后果至少两项不同）AI 自己做，用户问才摆出来。用户给了方向时写成同样的形状，再配一条对照。核心事件可以是本集新发生的事，写进第 7 节"新事实"。选定的候选写成事件链进第 7 节；被否的进第 6 节。

两轮都被否 → 不出第三轮，回第 3 节（§8）。

## 8. 回季线的时候

- 用户的话里有"没抓住""太薄""没有新的主线事件""跟主线不沾边""骨架""先别细节""这一季要去哪"。
- 第 3 节支柱待定两根以上，还没 pitch 过。
- 本集候选两轮都被否，而候选之间的差异检查成立——问题不在候选，在季。
- 连续两集"对论点的位置"都是"不动"，或代价总落在同一个人身上。

回季线只改相关的格；已拍的集不动。

## 9. 三条路径

| 情况 | 做法 |
|---|---|
| 新项目（没有正典） | 先填第 1 节和第 2 节的人物现在在哪，再按 §2–§4 聊季线；第 3 节每集一行只填前三集 |
| 进行中的剧 | 先把已拍各集的"对论点的位置""代价落在谁"倒填进第 3 节，看季的形状有没有歪（连续"不动"、代价总落在一个人、支柱没着落），再聊季线 |
| 有限季 / 短剧 | 支柱压成三根（第一次代价 / 中季转向 / 季终）；每集一行加"切点"；钩子只从本集已发生的事产生 |

## 10. 不做

- 不照节拍模板填集（Save the Cat、Harmon 圈只在题材手册里作形状参考）。
- 不把手段写进第 3 节；手段在第 7 节的事件链和场次表。
- 不让论点进台词。
- 不为了"有框架"把十几集都写满提案：未拍的集写到支柱和一句话为止。
- 不在季线层算制作成本；不用成本行、新人物 0、同框上限去筛季线和方向。
- 不用卡代替聊：季线和方向先交表再等反应，是 0.9.0 被否的做法。
