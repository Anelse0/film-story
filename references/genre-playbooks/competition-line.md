# 题材手册 · 竞技与职业线

适用：有赛制或行业日程的剧（颁奖季、乐队考核、球队选拔、比赛、晋级）；通常叠在关系剧或轻喜剧之上，作为场合与钟。本剧规则表优先于本手册。

## 1. 引擎
- **赛制是钟**：考核日、名单公布、Cut Day、提名公布。每个节点逼人在某一天做选择；一集只用一个节点。
- **输赢不是事件**；"谁替谁扛、谁被挡在门外、谁先到"才是（第一个到的人站在品牌方身边；替补的名字被人压上）。
- 人物线大于比赛（Friday Night Lights 的主创：全剧"是关于人物的"）；比赛只拍影响人物的那一下。
- 行业细节是人给的，不是搜出来的：从将要发生的事件反推问题，找当事人核实（`../story-development.md` §5）。

## 2. 先问的问题（写节拍单前答）
1. 这一集的**钟**是什么、离它几天？钟在哪一拍被提醒（一句话或一个画面）？
2. **信息段**里哪个数字或名字会**改变谁的决定**？其余的删。信息段多少秒？
3. 赛制这一集把**谁和谁放进同一间屋**、把谁**挡在门外**？
4. 结果出来之后**谁付代价**？付代价的人常常不是输的人（经纪人丢单、朋友被瞒）。
5. 行业细节标了**查实 / 推断 / 虚构**没有？行内人彼此**不解释**的事有哪些？
6. 这一集的竞技内容占多少秒？其中多少是人物在选择，多少是解说？

## 3. 单集形状
钟的提醒 → 规则把人放进一个场合 → 选择 → 结果只在改变决定时出现 → 下一个节点的影子（钩子）。考核或比赛本身那一集另算：赛前一场、赛中只拍转折那一下、赛后谁付代价。

## 4. 戏化手法
- **信息段压成一个画面加一句反应**：出赛板、名单、广告牌、手机屏；一个人看，另一个人看他的脸。
- 比赛只拍**影响人物的那一下**（三振之后并肩受掌声；考核时第一次合上拍子），其余用旁观者的反应代替解说。
- 排练与训练用**同一段内容的不同完成度**呈现进步（同一首歌、同一个动作）。
- 把**结果通知放在最难开口的时刻**（生日蜡烛前、照片墙上、天亮前）。
- 赛制让两人同台竞争时，先写他们各自和第三方的戏，再写同框；同框的张力来自各自已知的信息差。

## 5. 对白规范
- **工作语言可以直说**（`../dialogue.md` §9）：数字、名次、条款直接说，但只说会被用到的。
- **术语不解释**；用听的人的反应让观众懂。
- **行内人不对彼此说都知道的事**（品牌方来谈代言，不会不知道这是什么片）。
- 行内的**礼数**是规范：怎么称呼、谁先开口、什么能当面说。
- 不复述观众刚看过的赛况；赛后谈的是代价，不是比分。
- 信息段台词以秒计；超出的拆进动作或删。

## 6. 观众知情
两种选一种：观众先知道名单或结果、人物后知道（悬念：看他们什么时候知道）；或人物先知道、观众后知道（揭示：看他们怎么瞒）。别两边同时知道——那只剩解说。

## 7. 常见 AI 失误（从用户否决归纳）
- 解说式信息段；比赛拍成比赛；输赢当事件。
- 行业事件当场编造（候选"全在临时发明行业事件"）。
- 人物对彼此解释行规（"这里不可能总监不知道吧"）。
- 每集一个新赛制；钟不止一个。
- 信息段超时却没人标秒数；竞技内容吃掉关系戏的位置。
- 行内人举止失礼（当面看表、隔着人群喊人），人物被写低。

## 8. 形状参考（只借位置感）
- 体育片的"赛前—赛中—赛后"三段只用于考核日那一集。
- Save the Cat 的"一切皆失"只借倒数第二集最低点的位置感；Hacks"目标在这、我怎么拿到"用于每一集。
