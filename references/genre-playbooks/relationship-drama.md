# 题材手册 · 双人与群像关系剧

适用：两个主角（或一个小群像）之间的位置变化是全剧主线，职业或事业线提供场合；两人不互害。叠加职业线时同时读 `competition-line.md`。本剧规则表优先于本手册。

## 1. 引擎
- 事件 = **谁替谁做了决定**（Hacks：开除、官司、"敲诈什么"都是一个人替两人决定）。周围的人替两人做的决定是最稳的事件来源；两人之间只有一种事件：谁先开口、谁替对方守住什么。
- 张力来自**位置的有条件 / 拿不走**（Succession：Tom 有了地位但是有条件的，Shiv 的姓氏拿不走）。每集重新分配一次"谁的位置是有条件的"，不需要互害，也不需要亲密动作。
- 群像版：每集一对人在前、其他人在场作反应；下一集换一对；外人替观众问出两人之间不问的事。

## 2. 先问的问题（写节拍单前答）
1. 这一集**谁替两人做了决定**？决定落在哪一场、由谁带进来（在场者）？
2. 两人之间此刻**什么是有条件的、什么拿不走**？这一集之后变了没有？
3. 两人的**位置换手**在哪一拍（谁主动、谁握着信息、谁先开口）？没有换手 → 这一集的关系线在原地。
4. **关系推进**落在哪一拍？连续两集都落不到 → 补一场关系戏，不塞进任务集（`../story-framework.md` §2）。
5. 这件事两人是**当面**经历还是**分别**经历（`../dramatization.md` §3）？分别经历的事，谁先知道？
6. 两人之间**没说出口的那件事**这一集动了吗（更近 / 更远 / 没动）？动了的话代价落在谁身上？

## 3. 单集形状
外部决定进门 → 两人各自选择接不接 → 位置换一次手 → 收在两人之间一件没说出口的事上。每四到六集一集关系戏（两人单独、几乎没有外部事件）。

## 4. 戏化手法
- **旧信息再定价**：不加新事件，让一个人在新处境里重提旧话（Succession：投不下票时翻出第一季"你杀过人"）。
- **小空间**：一场戏不灵，放进更小的房间（Succession：三次关键时刻在卫生间；共用一间休息室）。
- **外人替观众问**：两人不会问彼此的事，由第三人当众问出；两人的回应各落在阶梯的不同级（`../dialogue.md` §8）。
- **借第三文本 / 借游戏说真话**（CMBYN 的骑士故事；Before Sunrise 的假电话）。
- **视线与不回应**（Normal People：食堂里谁也没对谁说话，吸引全在视线和翻页上）。
- **延迟、打断、偏移**：真正的回应晚一拍、被第三人打断、落在一句无关的话上。
- 时机：把两人必须回应的事放在最难开口的时候（上场前、天亮前、门铃响时）。

## 5. 对白规范
- **话多 = 没权**（Succession）：地位高的一方话少，可以不答、不解释。
- **粗鲁但不刻薄**，只有真受伤时才残忍一次（Hacks）；本剧规则如"互逗不互损"由此而来。
- 不点破的关系用**问对方要什么**的行动承载，不用情绪词（"What do you want to do?"）。
- 两人之间的事不用形容词说：用谁先开口、谁不接、谁替谁守住。
- 外人在场时守**场合的礼数**（不当面看表、不隔着人群喊人）——行内人的举止写低了，人物就写低了。
- 情愿的回应直接；不情愿的回应延迟、绕开、带理由（`../dialogue.md` §8）。

## 6. 观众知情
默认悬念：观众比两人多知道（两人各被喂了不同版本）。揭开时先让一个人知道，再让两人对上；两人对上的那一刻不写成对账戏——一句"他刚到"就够。两人单独的时间是观众最想看、人物最少说的地方，留着不揭也是办法。

## 7. 常见 AI 失误（从用户否决归纳）
- 两人宣布关系、轮流解释、对账到底（"这里根本就不重要"）。
- 让两人互害或点破（规则之外的禁区）。
- 关系变化写成情绪词和"笑"（七处"笑"被要求换成别的反应，且不能一对一删）。
- 每集都"更近"，没有代价落到任何人身上；代价的场被 hold 后没人提醒。
- 配角只捧哏；外人不替观众问，只复述主角。
- 把"方向"写成换地点、换场合，两人的位置没有换手（"跟主线不沾边"）。
- 候选全在两人单独的戏里，周围的人只从手机进来（规则"冲突从周围的人来"落空）。

## 8. 形状参考（只借位置感）
- Hacks："每一集都是目标在这、我怎么拿到"，拆完发现关系没位置就补一集。
- 浪漫线明确时，Mernit 七拍的"转轴（第二转折）"和"全失"只借位置：季中一次看似更近实则更远，倒数第二集一次最低点。不照拍数填。
