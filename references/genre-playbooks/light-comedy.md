# 题材手册 · 轻喜剧（含奇幻设定）

适用：调性边界写着"轻喜剧、不往暗黑或惊悚走"的剧；有超自然或特殊设定时，设定的规则是喜剧的来源。叠加竞技线时同时读 `competition-line.md`。本剧规则表优先于本手册。

## 1. 引擎
- 一场戏有一个**游戏**：先立基础现实（谁、在哪、在做什么），出现**第一个不寻常的东西**，然后交替**升级**与**探索**——"如果这是真的，还有什么是真的"（UCB 的场景游戏）。笑点是游戏升级的结果，不是单独的包袱。
- 设定型喜剧：**规则只讲一次**，之后每次用到规则都付代价；**限制比能力有趣**（Sanderson 第二定律）；观众懂多少，设定才能解决多少问题——所以设定制造的麻烦要多于它解决的（第一定律）。
- 事件来源：规则第一次被用到 → 露馅的风险 → 用一点本事加一个谎圆过去 → 代价留到下一集。

## 2. 先问的问题（写节拍单前答）
1. 这一场的**游戏**是什么？哪一个不寻常的东西在升级，升了几次？
2. 谁是**正常人**（看见荒唐、给出反应的那个），谁在**失常**（认真地做荒唐事、不知道自己好笑）？
3. 这一集**规则第一次被用到**的代价是什么？规则有没有被讲第二遍？
4. **尴尬的幅度**选哪一档？（Enough Said 灌木那场试了走、爬、跑三档，检验尴尬是否过度。）
5. 笑点落在**反应**上还是台词上？落在台词上的，是不是在解释笑点？
6. 这一集还像不像**调性边界**（不往暗黑、惊悚走；真受伤只有一次）？

## 3. 单集形状
基础现实（短）→ 不寻常 → 升级三次（一次比一次大一点，第三次换个方向）→ 代价 → 余韵。短集可以一场就是一个游戏；半集在一个场景里不是妥协，是方法（情景喜剧的三面台）。

## 4. 戏化手法
- 升级靠"如果这是真的"推，不靠音量、不靠更大的事故。
- **正常人的反应是笑点的载体**：先给反应的机会，再决定要不要台词；反应落在触发之后，不提前。
- **直接给人物他想要的，再放进威胁**（Barry）；不解释他们怎么脱身。
- 动作合物理位置：为了笑点让人做不到的事，笑点也站不住。
- 新人物、道具、声音在要用之前先露出来；登场带着状态。
- 露馅的悬念：观众知道规则，在场有人不知道（§6）。

## 5. 对白规范
- **正常人说正常话**；失常者说完整、认真的句子，越认真越好笑。
- 笑点不解释；语气词、停顿、重复确认代替包袱。
- 不用金句、不写成"台词感"；人说当下实际会说的话（结构信号见 `../dialogue-patterns.md` §5）。
- 下了决心的话要有过程（清嗓、视线落下再抬起）。
- 人物说话的方式来自他的来历（老派、客气、不会用缩写），不来自"要搞笑"。
- 已经发生的事不再用旁白或台词复述。

## 6. 观众知情
喜剧版的"桌下的炸弹"：观众知道规则（他们是使魔、他是外星人、她会魔法），在场的某个人不知道 → 每一句都可能露馅。揭晓时先让一个人看见，再决定要不要说破。

## 7. 常见 AI 失误（从用户否决归纳）
- 解释笑点；每句都抖包袱；失常者自知好笑、朝观众眨眼。
- 靠夸张表情和吸气制造喜感（"表情和吸气不夸张"）。
- 反应早于触发（"oh my god 早了"）。
- 规则讲两遍；或开场不先立世界和人物、拿观众没有上下文的结果句当钩子（"听不懂……不像是一部剧的开头"）。
- 为了笑点破坏物理位置（人不在那里却做到的动作）。
- 两个失常者对着说，没有正常人在场。
- 钩子是新谜题，不是本集已发生之事的未完成部分。

## 8. 形状参考（只借位置感）
Harmon 的八步圈（舒适 → 需要 → 进入陌生 → 适应 → 得到 → 付出代价 → 回来 → 改变）：一集或一场的弧可以照这个顺序检查"得到之后有没有付出"，不照步数填。
