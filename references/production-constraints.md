# 制作约束怎样进入剧本层（模板 + Offset 实例）

剧本阶段不拿时长当硬约束（Offset 已定），但节拍单要给生产一张成本表，让"换景、加人、群戏、长无声"在写之前就看得见。

## 通用（AI 视频生成短剧）
| 约束 | 对剧本层的意思 |
|---|---|
| 一条生成 ≤ 30 s，一场通常拆 1–3 条 | 一场的台词量 ≈ 秒数 × 4 词；超过 100 词的场要能切成有各自落点的段 |
| 每个场景、人物、服装都要参考图 | 新景、新人物、新服装 = 真实成本；节拍单标"新" |
| 竖幅 3:4 / 9:16 | 三人以上同框要拆正反打或纵深错落；群戏能用画外声就用画外声 |
| 表情会被放大；两段式表情只演前半段；安静收尾会被压缩 | 剧本里的情绪变化写成渐进加深的一个动作，不写"愣一下再笑"；收尾段要有事件或声音落点 |
| 情绪不突变 | 峰值也写成前面几拍一路加深来的 |
| 无 BGM、无字幕 | 信息只能靠画面、台词、画内声 |
