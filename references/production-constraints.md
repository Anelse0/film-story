# 制作约束怎样进入剧本层

剧本层不拿时长当硬约束，但节拍单要给生产一张成本表，让换景、加人、群戏、长无声在写之前就看得见。

**数字以项目约束文件的 `## 制作参数` 为准**（英文语速、中文语速、单条生成上限；格式见 `templates/constraints.md`）。两个检查脚本从场景文件往上找 `story/constraints.md` 读这一节，也可以用 `--wps` / `--cps` 临时指定；都没有时只报词数或字数，不估秒、不提拆条。下表里的数字只是示例。

| 约束（AI 视频生成短剧的常见情况） | 对剧本层的意思 |
|---|---|
| 单条生成有时长上限（例：30 s），一场通常拆 1–3 条 | 一场的台词量 ≈ 单条上限 × 语速 × 条数；超过的场要能切成各有落点的段 |
| 每个场景、人物、服装都要参考图 | 新景、新人物、新服装是真实成本；节拍单标"新" |
| 竖幅画面 | 三人以上同框要拆正反打或纵深错落；群戏能用画外声就用画外声。同框人数看动作描写（在场不说话的人也算），不按说话人数算 |
| 信息通道（有没有配乐、字幕） | 按项目定；没有字幕时，信息只能靠画面、台词和画内声 |
| 估出来的秒数 | 是口播时长，不是成片时长；成片另加动作、停顿和剪辑 |

渲染相关的限制（表情被放大、景别漂移、安静的收尾被压缩等）归导演层，剧本层不讨论（SKILL.md §7）。某部剧对情绪写法、表情、调度的要求写在项目自己的 `story/rules.md` 和导演层文件里，不放进本 skill。
