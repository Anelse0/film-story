# 公开出处：案例、奖项与工具

方法文件（`scene-work.md`、`dialogue.md`、`story-development.md`、`dialogue-patterns.md`）只写案例短名，背景、链接与定位都在这里，不在各文件里重复。只转述，不复制剧本原文；公开引用原话之前要对原页。

来源：《film-story 0.6.0 专业创作实务调研与升级方案》（2026-10-24，作者本地，不随仓库分发；基线为本仓库 0.5.0）。同日审阅抽查了其中 10 条访谈与方法出处，依据是网页摘要与短摘录。

**证据类型**：创作者回忆（访谈、讲座、注释，属本人对过程的回顾）/ 稿件对照（公开的前后稿可以互相比对）/ 本 skill 的稿面分析（对公开稿件的解读，不是作者说明的动机）/ 产品文档。

**复核**：核实 = 10-24 抽查与方案一致；部分核实 = 抽查后按原文改了措辞或范围；未复核 = 抽查时打不开，方法保留、引用时加注；沿用 = 沿用方案的复核，本次未抽查。

## 稿件与创作者

### 风骚律师
- 出处：Heather Marion 本人访谈 — https://medium.com/@IdahoReview/an-interview-with-better-call-saul-screenwriter-heather-marion-9f56d6a1d883
- 类型：创作者回忆
- 支持：讨论先放临时卡，逐场深入后变成措辞明确的正式卡；执笔时从卡片列场、翻编剧室笔记找情节与对白；医疗细节请急诊护士核实。
- 不支持：没有取得那约 400 页讨论笔记原件；12–17 页的叙述性大纲是该剧的实例，不是长度要求。
- 用在：`story-development.md` §1
- 复核：沿用

### 绝命毒师《Sunset》
- 出处：Peter Gould、Thomas Schnauz 的 Fresh Air 访谈 — https://freshairarchive.org/segments/breaking-bad-writers-it-theres-no-more
- 类型：创作者回忆
- 支持：Hank 把 Walt 和 Jesse 堵在房车里，最后用假报 Marie 出事的电话把他引走；被否的办法有的成了 Jesse 当场提出的想法。
- 不支持：具体归功于谁，两人的记忆不完全一致；假电话是 Gould 提的，不写成全编剧室的共同决定。
- 用在：`story-development.md` §2
- 复核：核实

### 聚焦
- 出处：Josh Singer 文章及两版完整场景，Creative Screenwriting — https://www.creativescreenwriting.com/cswcms/oscar-winning-josh-singer-on-writing-spotlight/
- 类型：创作者说明 + 稿件对照
- 支持：Mike 与 Robby 决定是否采访 Saviano 的两稿，信息基本不变，新稿把它放进惊讶、明确决定、自我怀疑的过程；关键决定说得更明确，仍然有效。
- 不支持："说明性台词都该删"。新稿里上级邮件的内容只是暗示，没有在场内读出。
- 用在：`scene-work.md` §4；`dialogue-patterns.md`"不要误删的写法"
- 复核：核实

### 大鱼
- 出处：修订序列大纲（标"3/31/00 Draft"，PDF 第 4 页，序列 23–27）— https://johnaugust.com/downloads_ripley/bf-outline.pdf ；最终制作稿（PDF 第 114–121 页，场 181–193）— https://johnaugust.com/downloads_ripley/big-fish.pdf ；原始一页大纲 — https://johnaugust.com/downloads_ripley/bf-original-outline.pdf ；资料入口 — https://johnaugust.com/library
- 类型：稿件对照 + 本 skill 的稿面分析
- 支持：同一个"化鱼"的故事从葬礼之后讲给儿子，改为临终的父亲请求结局、Will 当面编出来；改变时机与听众，使主角必须当场回应。
- 不支持：作者亲口说明的修改动机；最终稿封面只有版权年份 2003，未标编修日期。
- 用在：`scene-work.md` §4
- 复核：沿用

### 查理和巧克力工厂
- 出处：2004-06-16 蓝色修订页（正文第 44 页）— https://johnaugust.com/wp-content/uploads/2022/01/Charlie-BLUE.pdf ；2004-07-08 粉色修订页（同处及正文第 64 页）— https://johnaugust.com/wp-content/uploads/2022/01/Charlie-PINK.pdf ；粉页备忘录 — https://johnaugust.com/wp-content/uploads/2022/01/note-about-pink-pages.pdf
- 类型：稿件对照 + 作者备忘录

- 不支持："重复都该删"。
- 用在：`dialogue.md` §3；`dialogue-patterns.md`"不要误删的写法"；`templates/revision-note.md` 的本轮目标
- 复核：沿用

### 第一头牛
- 出处：Kelly Reichardt 本人访谈，Fandango — https://www.fandango.com/movie-news/kelly-reichardt-discusses-first-cow-a-western-unlike-any-other-754082
- 类型：创作者回忆
- 支持：初稿写到偷奶被追时，追问追来的究竟是谁；扩写宅内人物和活动，再回到前面把相关人物提前安排进故事。
- 不支持：笼统地"多埋伏笔"。
- 用在：`story-development.md` §3
- 复核：沿用

### 小妇人
- 出处：Greta Gerwig，Scriptnotes 433 — https://johnaugust.com/2020/scriptnotes-ep-433-the-one-with-greta-gerwig ；剧本镜像（PDF 第 3 页为记号说明，第 71 页对应印刷页 68）— https://thesuccessfulscreenwriter.com/wp-content/uploads/little-women-2019.pdf
- 类型：创作者说明 + 稿面
- 支持：Amy 与 Laurie 的对话用斜线标出 Laurie 从哪个词切入；排练练准切入点，让需要听清的词保持可辨；随后 Amy 关于婚姻的长段有完整论证，长句和论辩可以承载关系。
- 不支持：按数量给每场加打断。镜像只核验了可提取的文字，没有做页面截图核验。
- 用在：`dialogue-patterns.md`"不要误删的写法"
- 复核：沿用

### 婚姻故事
- 出处：Noah Baumbach 逐场解析，Vanity Fair "Notes on a Scene" — https://www.vanityfair.com/video/watch/notes-on-a-scene-noah-baumbach-breaks-down-the-marriage-story-courtroom-scene ；剧本镜像印刷页 111–112 — https://assets.scriptslug.com/live/pdf/scripts/marriage-story-2019.pdf?v=1729114949
- 类型：导演回顾 + 稿面
- 支持：法庭戏让夫妻通过听见律师的发言作反应；稿面可见听者的反应与律师站起、坐下的动作。
- 不支持：坐着更有力量、可脱下的外套来自排练和试装的回顾，不是该稿写明的内容；具体调度归导演层。
- 用在：`dialogue.md` §5
- 复核：沿用

### 月光男孩
- 出处：Barry Jenkins 本人访谈，The Ringer — https://www.theringer.com/2017/02/09/movies/barry-jenkins-on-crafting-the-sincerity-of-moonlight-bfb2a78a7cfc
- 类型：导演回顾
- 支持：母子重逢时母亲点不着烟，他私下让饰演儿子的演员替她点；照料的举动引出了母亲的道歉。直接的表达靠前面的行动成立。
- 不支持：即兴适合所有项目。该片预算不允许提前组织排练；这是现场发现，本 skill 只接收和记录这类发现，不假装做过演员实验。
- 用在：`dialogue-patterns.md`"不要误删的写法"；`scene-work.md` §7
- 复核：核实

### 海边的曼彻斯特
- 出处：Kenneth Lonergan 访谈，TheWrap（最后两组问答）— https://www.thewrap.com/kenneth-lonergan-manchester-by-the-sea-casey-affleck-i-cant-beat-it-scene/ ；WGA East 访谈 — https://www.wgaeast.org/onwriting/kenneth-lonergan-manchester-by-the-sea/
- 类型：创作者回忆
- 支持（TheWrap）：写 Lee 与 Randi 的街头重逢时在脑中扮演双方；她想接近他，他想结束谈话又不愿伤她。（WGA East）人物在铲雪、处理事务的样子里变得清楚；笔记本先记人物与场景，卡住时也补大纲。
- 不支持：原文没有"再次（伤害）"；没有把断句、抢话、说不完归因于这种牵制——那是本 skill 的推断，引用时要标出。
- 用在：`scene-work.md` §2；`dialogue.md` §2
- 复核：TheWrap 部分核实；WGA East 沿用

### Walking and Talking
- 出处：Nicole Holofcener 的 Scenario 访谈（原采访者 Tod Lippy 保存）— https://www.todlippy.com/writing/interviews/holofcener
- 类型：创作者回忆
- 支持（待复核）：婚礼前夜两位朋友坐在泳圈里谈"婚姻不会改变友谊"，排练时演员不信；改写为 Amelia 在湖里托着仰浮的 Laura——保留关系任务，换交往方式。
- 不支持：没有取得两稿逐字核对；不能据此断言成片没有对白。
- 用在：`dialogue.md` §2（注明未复核）
- 复核：未复核（10-24 两次打开均为 403；访谈存在，细节未核）

### Enough Said
- 出处：Holofcener DGA 访谈（relationship / day one 两组问答）— https://www.dga.org/craft/dgaq/issues/1403-summer-2014/dga-interview-nicole-holofcener ；The Playlist 访谈（improvised 问答）— https://theplaylist.net/interview-nicole-holofcener-talks-working-with-the-late-james-gandolfini-julia-louis-dreyfus-for-enough-said-20130912/
- 类型：创作者回忆
- 支持（DGA）：与两位主演在客厅分三次读剧本，讨论不喜欢或不理解的句子，记下临场说出的台词；原稿已写到手，看到 Gandolfini 真实的大手才想到"桨（paddle）"的比喻；灌木那场试了走、爬、跑等不同幅度，检验尴尬是否过度。（Playlist）排练里选中的说法拍摄时再说一次，搭档演首次听见。
- 不支持：整场即兴。
- 用在：`scene-work.md` §7
- 复核：DGA 核实（比喻按原文写作 paddle，方案作"船桨"）；Playlist 沿用

### Sideways
- 出处：Jim Taylor 访谈（early drafts / Maya should have her own speech）— https://leoadambiga.wordpress.com/2016/06/30/jim-taylor-the-other-half-of-hollywoods-top-screenwriting-team-talks-about-his-work-with-alexander-payne-2/ ；2003-05-29 稿镜像（PDF 第 65–67 页）— https://www.thescriptsavant.com/movies/Sideways.pdf ；Alexander Payne 逐镜回顾，DGA（2025-11-18）— https://www.dga.org/News/Guild-News/2026/CraftArticles/1225-Shot2Remember-SIDEWAYS
- 类型：创作者回忆 + 本 skill 的稿面分析 + 导演回顾
- 支持：早稿扩写 Miles 的谈酒独白，后稿意识到 Maya 也应有她自己的那一段；（稿面分析）独白落在"尝试接近—承受不了—躲开"的行为里，才成为当前关系的事件；（DGA）四人约会按经过的阶段改变醉态、注意力和交流。
- 不支持：没有核对全部早稿；拍摄方法不能倒推为初稿的写作程序。
- 用在：`dialogue.md` §5；`scene-work.md` §2 第 3 步
- 复核：沿用

### 迷失东京
- 出处：Sofia Coppola，Fresh Air（scripted / More Than This 段落）— https://freshairarchive.org/segments/filmmaker-sofia-coppola

- 支持：两人初见与彻夜谈心主要按剧本拍；卡拉 OK 是现场发现。自然的交流可以写定，也可以从现场找到。

### Get Out
- 出处：Jordan Peele 剧本注释 25–26，Film Comment 经授权转载 — https://www.filmcomment.com/excerpt-get-out-the-complete-annotated-screenplay-jordan-peele/
- 类型：创作者注释
- 支持：外面的 Walter、Georgina 让 Chris 不安，屋里才暂时显得安全；Chris 不愿被催眠。注 26：Keener 亲自体验催眠后的讨论，帮他们找到 Missy 突然越界之前需要呈现的共情与信任。
- 不支持：原注是"Chris 不愿被催眠"，不是"Chris 没有同意"。
- 用在：`scene-work.md` §2 第 1 步

### Fargo
- 出处：Coen 兄弟逐场访谈，Sight and Sound（第 2 节）— https://www.bfi.org.uk/sight-and-sound/features/joel-ethan-coen-brothers-fargo-1996 ；剧本文本镜像（PDF 第 11–14 页）— https://www.sellingyourscreenplay.com/wp-content/uploads/screenplay/scripts/Fargo-%281%29.pdf
- 类型：创作者回忆 + 本 skill 的稿面分析
- 支持：TruCoat 推销戏源于 Ethan 买车的经历，对话接近当时的情形；（稿面分析）Jerry 声称去请示、实际在和同事谈球票，回来宣布让价，说话与实际行动的差异、谁控制交易程序构成张力；有用的重复保留。
- 不支持：镜像未署稿期，不用来推断修订顺序。
- 用在：`dialogue.md` §3；`story-development.md` §5

### Michael Clayton
- 出处：Tony Gilroy，BAFTA 编剧讲座（2013）— https://www.bafta.org/media-centre/press-releases/screenwriters-lecture-series-2013-tony-gilroy/

- 支持（待复核）：处理肇事逃逸客户的一场早于整部电影成形；先探索对话，再把动作与对白串成粗稿；卡住时与合作者分角色接话。
- 不支持：这一页可能是新闻稿而非讲座全文；不照搬长片粗稿页数。"交替代入双方"以海边的曼彻斯特为主要出处，不以本条为据。
- 用在：方法文件不引用，只在此备查
- 复核：未复核（10-24 打开为 403）

### 社交网络
- 出处：Aaron Sorkin 访谈，Time Out（2010-09-29）— https://www.timeout.com/film/aaron-sorkin-on-screenwriting ；Sorkin 美国国会图书馆访谈（2024-11，PDF 第 4 页）— https://www.loc.gov/static/programs/national-film-preservation-board/documents/Interview_Aaron-Sorkin.pdf

## 方法与播客

### John August《How to write a scene》
- 出处：https://johnaugust.com/2007/write-scene
- 类型：创作者方法说明
- 支持：先想象表演、做快速速写，再从空白写完整场；大多数场景不需要出人意料的瞬间。
- 不支持：把写场写成固定步骤的展示。
- 用在：`scene-work.md` §2
- 复核：核实（第 5、8、9、10 步）
