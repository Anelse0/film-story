# 正式剧本：标准格式与写法

用法：第 4 步写剧本正文、第 5 步改正文时读。头部字段见 `templates/screenplay.md`；四个阶段各管什么见 SKILL.md §2。格式的公开出处见 `sources.md`"工具"。

剧本一集一个文件，是 Markdown；元素是行业标准剧本的那几种。标准页和 PDF（Courier 12 pt、固定页边距、扉页、页码）由脚本从 Markdown 导出，不手排；别处来的 PDF 也读得回来（§5）。

## 1. 元素

| 元素 | Markdown 里怎么写 | 写什么 | 标准页上的位置 |
|---|---|---|---|
| 场标记 | 注释行，写在这一场第一个场景标题的上一行：`<!-- S03 · THE BAR -->` | 场号和名字，同节拍单；一场可以有几个场景标题 | 不显示 |
| 场景标题（Scene Heading / Slugline） | 二级标题：`## INT. KITCHEN - NIGHT`；有正文标记的文件里，二级标题都算场景标题 | `INT.` 或 `EXT.` + 地点 + ` - ` + 时间（DAY / NIGHT / LATER / CONTINUOUS），全大写；地点用约束文件登记的名字 | 顶格 |
| 场内小标题 | 三级标题：`### AT THE WINDOW` | 同一场里换到另一处，时间不断 | 顶格 |
| 动作描写（Action） | 普通段落，段间空一行 | 观众看得见、听得见的，现在时；一段一个画面 | 顶格，通栏 60 格 |
| 角色名（Character） | 加粗单独一行：`**MARA**`；下一行紧跟台词，中间不空行 | 全大写。画外的声音写 `**MARA (V.O.)**`，人在场但不在画内写 `(O.S.)`，隔了动作接着说写 `(CONT'D)` | 缩进 20 格 |
| 括注（Parenthetical） | 角色名或台词下面单独一行：`(to the glass)` | 对谁说、声源、从哪个词抢话；不写情绪 | 缩进 15 格，宽 25 格 |
| 对白（Dialogue） | 紧跟角色名或括注；一句一行，不手动折行 | 台词 | 缩进 10 格，宽 35 格 |
| 片名卡、本集完 | 加粗单独成段，后面空一行：`**END OF EPISODE**` | 少用 | 居中 |
| 转场 | 单独一行：`CUT TO:`、`FADE OUT.` | 转场是导演层的事，剧本层一般不写 | 靠右 |

角色名和片名卡都是加粗单独一行，区别在下一行：紧跟台词的是角色名，空一行的是片名卡。脚本也按这个分。

## 2. 示例（原创，演示用）

```markdown
## INT. NOODLE SHOP - NIGHT

The last table. Chairs are already up on the others.

MAYA counts the till. LEO stands at the door, coat on, not leaving.

**LEO**
You changed the sign.

Maya keeps counting.

**MAYA**
Three weeks ago.

He looks at the new sign through the glass. From inside it reads backwards.

**LEO**
(to the glass)
It's nice.

The till drawer shuts.
```

- "Maya keeps counting." 是留白：她没接话，这件事单独占一段，前后各空一行。
- 没有一句写谁心里怎么想：他不走、她不抬头、抽屉关上，都是看得见、听得见的。
- 括注只出现一次，写的是对谁说。

## 3. 格式要求的写法

这套格式管两件事：动作描写简练，留白看得见。下表是通用默认，本剧规则另有规定时以本剧为准。

| 约定 | 为什么 | 不这样写 | 这样写 |
|---|---|---|---|
| 动作只写看得见、听得见的 | 写了心理，演员和导演拿不到可拍的东西 | 她后悔刚才说重了。 | 她把说到一半的话咽回去，低头拧瓶盖。 |
| 一段一个画面 | 段落是观众看的单位；标准版面一段通常不超过四行 | 进门、寒暄、落座、窗外的雨写成一段 | 观众看的对象换了，就另起一段 |
| 留白单独成段 | 反应和停顿各占一段，读的人一眼看到这里有空间 | 塞进括注：`(沉默很久)` | 这一刻看得见的事另起一段：他没接话。水烧开了。 |
| 听的人的反应跟在引起它的那句后面 | 隔远了，看不出是被哪句引起的 | 整段对白写完，再补一句"她很惊讶" | 那句之后另起一段：她停下筷子。 |
| 括注少用 | 读法留给演员 | `(难过地)`、`(冷冷地)` | 删掉；不写就会弄错对象或声源时才留 |
| 不写机位、景别、剪辑 | 那是导演层的决定 | `CLOSE ON`、"镜头推近" | 写观众此刻看见的东西 |
| 英文动作描写里，人物第一次出场名字全大写 | 读的人一眼知道有新人物进来 | — | `A WAITER, twenties, apron untied.` |

留白不是加停顿：只写这一刻真有的事（一个动作做完、一次不回答、一个声音）。没有就不写，不为了"有呼吸"添动作（`dialogue.md` §4"不够自然"一行）。

## 4. 语言与对照翻译

- 对白用剧的语言。要对照翻译时，译文紧跟在那句台词下面另起一行；脚本按全文多数台词的语言统计，另一种语言的行算对照。
- 一份文件、两种读法：带对照的 Markdown 是工作稿；导出时加 `--no-translation`，得到只有一种语言的干净稿，页数才接近"一页一分钟"。
- 动作描写用哪种语言由项目定，写在项目的 `story/README.md`。
- 中文对白的项目写法相同；场景标题写成 `## 内 / 外 · 地点 · 时间` 或 `## 内景 地点 - 时间`（场号在场标记里，标题不再写）。
- 另一种语言的版本（场景标题、动作、括注换一种语言，对白一字不动）是另一个 Markdown 文件，照样出 PDF。头部的"说明"写明它译自主稿的第几版、时长看哪一种语言的页数（中文字比 Courier 的西文宽，页数不能当时长）。对白用 `compare_drafts.py <主稿> <另一种语言的版本> --dialogue-only` 核对。

## 5. 标准页、PDF 与导出

标准页的硬指标（导出脚本按这个排；出处见 `sources.md`"工具"）：

- 字体 Courier 12 pt。等宽，一个字符一格，页数才能估时长。中日韩文字一个字宽 12 pt，折行按实际宽度算（通栏一行 36 个字）。
- 页边距：左 1.5 in（留装订），右、上、下 1 in。动作通栏 60 格；对白左缩 1 in、宽 3.5 in；括注左缩 1.5 in；角色名左缩 2 in。
- 一页 54 行。英文剧本一页约一分钟，是经验值；对照翻译行和中文动作描写会让页数偏多，口播秒数看 `check_dialogue.py`。
- 页码在右上角，从正文第二页起；扉页不编号。对白跨页时页底加 `(MORE)`，下一页的角色名后加 `(CONT'D)`；场景标题和小标题不留在页底；动作段跨页时断在句子中间。

Markdown 和 PDF 是同一份稿的两种样子，哪一项在哪一边：

| 信息 | Markdown 里 | PDF 上 |
|---|---|---|
| 剧名、集名 | 一级标题，用 ` · ` 分开 | 扉页居中，各占一行 |
| 版本、稿次标签 | "版本："一行里"依据"之前、日期之前的部分，照原样印（`Draft v1.4 (Lock Candidate)`） | 扉页，标题下面 |
| 日期 | "版本："一行里最后一截带数字的；"依据"不印 | 扉页左下角 |
| 说明 | "说明："一行 | 扉页左下角，日期上面 |
| 场景标题、小标题、动作、角色名、括注、对白、片名卡、转场 | §1 | 标准版面；粗体、斜体的星号不印 |
| 页数 | "页数："一行，出整集 PDF 时脚本回填 | 页码 |
| 场标记；承接、新事实、状态、本版改动、历次 | 有 | 不印（这一版改了什么另出改动清单，`polish.md` §7） |
| 页码、`(MORE)`、`(CONT'D)` | 没有：分页是排出来的 | 有 |

```bash
python3 scripts/render_screenplay.py <剧本.md>                             # 终端里看标准版面，报页数
python3 scripts/render_screenplay.py <剧本.md> --pdf <整集.pdf>            # PDF：扉页、页码、(MORE) / (CONT'D)
python3 scripts/render_screenplay.py <剧本.md> --html <整集.html>          # 同一份排好的页，浏览器里看
python3 scripts/render_screenplay.py <剧本.md> --fountain <整集.fountain>  # 导入 Final Draft、Highland 等
python3 scripts/render_screenplay.py <剧本.md> --scene S03 --md <单场.md>  # 取出一场另存（交导演层要单场文件时）
python3 scripts/render_screenplay.py <别处来的.pdf / .fountain / .txt> --md <稿.md>  # 转成 Markdown
```

- `--scene S03` 只取一场（可写几场：S03,S04）；`--no-translation` 去掉对照翻译行；`--title` 指定标题（不给时用头部的一级标题）。几个选项可以一起用。
- 出 PDF 要本机有 Chrome、Chromium 或 Edge（脚本自己分页，再让浏览器无头打印）。找不到时写出排好页的 HTML 并说明。
- 脚本只转换格式，不改字。剧本文件本身就是整集稿，要改就改它；导出的页面和文件不手改，改完重新导出。
- 场标记在 Fountain 里写成分节行（`# S03 · THE BAR`），转回 Markdown 时还原；标准页和 PDF 上不显示。
- 一场一个文件的旧稿：把几个文件按顺序给脚本，加 `--md` 拼成一份。
- 结尾的"格式提示"只报和标准格式不一样的地方（场景标题的写法、角色名大小写），不改。扉页排不下（标题或说明太长）时提示有几行没印。

**读 PDF。** 别处来的稿（另一个工具、另一位合作者导出的 PDF）：

- 只是检查或比稿，直接给脚本：`check_dialogue.py <稿.pdf>`、`check_constraints.py <稿.pdf>`、`compare_drafts.py <旧.pdf> <新.pdf>`（`.fountain` 也行；`.txt` 先用 `--md` 转）。这时报的行号是转成 Markdown 之后的，头部必填项不查。没有场标记的两份稿按场景标题对齐；加 `--dialogue-only` 时按场景的先后对齐，两个语言版本的标题不一样也对得上。
- 要接着改，先用 `--md` 转成 Markdown：扉页读成头部，承接、新事实、状态写着"待补"，场标记也要补，补完再当入口用。
- 怎么认：按每一行离左边距多远认元素，居中的是片名卡；页码、`(MORE)`、`(CONT'D)` 去掉。两行是同一段折出来的还是各自一行，看上一行排没排满：下一行开头的词接在上一行后面放得下，就是另起的一行。对白里手动分的行、台词下面的对照翻译因此都留得住。
- 只认标准版式、带文字层的 PDF，扫描件读不了；要 macOS（用系统自带的 PDFKit，经 `swift` 运行）。读不了时脚本写明原因。

读回来和原稿不一样的地方（PDF 上本来就没有，或者版面上分不出来）：

| 情况 | 读回来 |
|---|---|
| 场标记、扉页以外的头部 | 没有，要补 |
| 粗体、斜体的星号，连着的两个空格 | 没有 |
| 对白里上一行恰好排满一行，下一行是手动另起的 | 并成一行 |
| 全大写、不以句号结尾的短动作行（`BANG`） | 读成小标题 |
| 七个词以上的小标题、中文的小标题 | 读成动作行 |
| 不以 INT. / EXT.（内、外）开头的场景标题 | 读成小标题 |
| 小写写的场景标题、小标题 | 版面上是大写，读回来也是大写 |
| 折成三行以上的片名卡 | 认不全 |
| 比一行还宽的词（网址） | 被硬切，中间多一个空格 |
| 别的工具导出的 PDF 里，动作段恰好在句末跨页 | 读成两段 |

照 §1 写的稿，本脚本写出的 PDF 读回来，正文和原稿一字不差（上表除外；有测试）。

## 6. 脚本给的动作描写线索

`check_dialogue.py` 在有正文标记的文件上多报三条，都是表面线索，阈值是通用默认。有场标记时，文末另按场合计台词量，用来对照节拍单每场的时长。

| 线索 | 怎么算 | 看什么 |
|---|---|---|
| 动作段偏长 | 一段折合标准版面超过四行（一行 60 格；中文一个字 12 pt，一行 36 个字） | 是不是几个画面写进了一段，或夹着说明 |
| 动作描写里的心理词 | 感到、觉得、意识到、realizes、knows 这类词 | 观众看不见的改成看得见的，或删；有意保留的不动 |
| 连续对白 | 八句以上的对白中间没有一段动作 | 这一段里听的人有没有反应的位置；快速来回的戏保留 |

## 7. 旧稿

已采用、已拍的旧稿不为改格式而改，一场一个文件的也不并成一集一个文件。脚本照旧读得出旧写法：不带 `##` 的标题行（`场 NN · 内 · 地点 · 日`）、同一行的 `角色名：“台词”`、角色名后面空一行的导出稿。新写的场和整场重写的场按本文件。
