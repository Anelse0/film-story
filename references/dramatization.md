# 戏化：从事件链到一场戏

用法：方向卡定了、写节拍单之前读（SKILL.md 第 3 步）；节拍单或场景稿被判"叙事感不对、心理状态不对""人物在交换信息"时读 §9。与 `scene-work.md` 的分工：本文件决定**这场是什么戏**（谁在场、何时进出、什么价值从哪转到哪）；`scene-work.md` 把它写成正文、改到成立。案例只写短名，出处与复核状态见 `sources.md`。

方向卡给的是事件链（发生了什么）。戏化决定每件事**怎样被经历**：由谁、在谁面前、以什么形式（当面 / 电话 / 第三人转述 / 看见）、从哪一刻进哪一刻出、场里什么价值从哪转到哪、观众比人物多知道什么。同一件事能戏化成几种不同的场，选法只有一条：哪一种让主角当场必须回应（大鱼：同一个"化鱼"的故事，从葬礼后讲给儿子，改成在临终的父亲面前当场编出来）。

## 1. 操作顺序（从方向卡到节拍单）

| 步 | 做什么 | 写在哪 |
|---|---|---|
| 1 | 事件链里每件事过三问（§2）；答不出的合并进别的场、改成转述，或让它进入一个决定 | 节拍单"每场的三问与转向"表 |
| 2 | 每件事选在场者与形式（§3）；定场 | 同上 |
| 3 | 每场定开场值 → 结束值与转折拍（§4） | 同上 |
| 4 | 排顺序：A 线拍之间放 B 线拍的依据（§6）；进晚出早（§5） | 场次表"A / B 线"列 |
| 5 | 逐拍写节拍表，每拍标变化轴（§7）；查连续性 | 节拍表 |
| 6 | 集尾钩子只从本集已发生的事产生（§8） | 单集四问 |
| 7 | 预检：关键拍成立条件、与本剧规则的偏离、对论点的位置 | 节拍单末尾 |

## 2. 三问闸门

每场一行：**谁要什么 / 得不到会怎样 / 为什么是现在**（Mamet 致《The Unit》编剧的备忘录：答案是试纸，答得出才是戏；观众不为信息收看）。再加 Sorkin 的两个检查：信不信这个意图，信不信这个障碍。

- 答不出"要什么"：这场是信息。三种处理：合并进一个有事要办的场；改成第三人转述或一条消息；让信息进入一个决定（`scene-work.md` §4）。
- 答不出"得不到会怎样"：没有障碍，对白会变成互相解释。给对面的人一个自己的利害，或把场挪到更难开口的时候。
- 答不出"为什么是现在"：场可以放在任何时候，就说明它不该在这里。找一个钟（上场前最后一刻、天亮前的回应时限、门铃）。
- 例外：关系余韵、陪伴、观察的场，"要什么"可以很小（想多待一会儿、不想回到那句话），但"为什么是现在"要答得出，并在三问表里写明它在整集里的作用（`scene-work.md` §6 第一行）。

## 3. 选在场者与形式

一件事先列两三种戏化，再选让主角当场必须回应的那一种。

| 问 | 选项 | 选法 |
|---|---|---|
| 谁在场 | 两人单独 / 加一个有自己利害的第三人 / 当着一群人 | 换在场者比加台词便宜；第三人能让旧信息再定价（Succession：Shiv 投不下票时翻出第一季"你杀过人"） |
| 什么形式 | 当面 / 电话 / 转述 / 看见但没被看见 / 一条消息 | 信息分布决定：谁必须看见（断背山：Alma 必须看见两人接吻，否则她无从知道）；谁不该知道（台账 B 节） |
| 什么时候 | 事前 / 事中 / 事后；有钟 / 没钟 | 有钟的时刻优先；事中比事后强迫人回应 |
| 在哪 | 公开场合 / 私下 / 对方的地盘 | 小空间逼人靠近；对方的地盘换主动权（Succession：一场戏不灵，试试放进更小的空间） |

写进三问表的"在场者与形式"一格：选了什么，为什么不是另一种（一句）。

## 4. 价值转向

每场写**开场值 → 结束值**和**转折拍**（McKee：场 = 通过冲突让一个价值从正到负或从负到正；没转向的不是场）。

- 价值只选一个，写成一对：安全 / 危险、信任 / 怀疑、知情 / 不知情、主动权在谁、亲近 / 疏远、有条件 / 拿不走。
- 转折拍是转向发生的那一拍，由行动或揭示引起；一场以一次转向为主。
- 转向不等于反转：一句"他刚到"让两人发现经纪人在编，就是转向。
- 场末回到开场值 = 没转向。两种出路：删或合并；或写明这是余韵场，它的作用在集的层面（§2 例外）。
- 一集里连续两场转的是同一个价值、同一个方向 → 合并，或让第二场转另一个价值。

## 5. 进晚出早

- 从冲突已经在场的那一刻进；人物的来路不演，必要时一句带过。
- 转向落定后尽快出；不加替观众总结的句子（`scene-work.md` §2 第 4 步）。
- 竖屏短集的切点可以落在一句话中间、一个动作做到一半（Farber：上一集结束在"你睡了我丈夫"，下一集从同一句重新开始）；切点写进场次表。

## 6. A / B 线交织

A 线拍之间放一拍 B 线，要有下面四种依据之一，不为"换口气"而换：

| 依据 | 例 |
|---|---|
| 时间需要过去 | 两人在休息室对账时，楼上的桌子已经坐了人 |
| A 线刚转向，观众需要消化 | 决定不问之后切到别处，再回来上场 |
| B 线的信息会改变 A 线下一拍的选择 | 观众先看见对手已经坐到品牌方身边，再看主角在照片墙上约好溜 |
| 跑线每次出现都有一点变化 | 未接来电一次比一次多 |

竖屏短集通常只有 A 线加一条跑线；B 线不够一场就并进 A 线的在场者里。

## 7. 变化轴

每拍标哪一轴变了（Mazin：变化发生在内在、人际、外部三轴；场是正题 → 反题 → 合题）。

| 连续三拍以上 | 说明 | 做法 |
|---|---|---|
| 只有外部轴（信息、事务、位置） | 人物在办事，不在经历 | 让一拍落在人际轴：谁的位置、谁握着信息换了手 |
| 只有内在轴 | 戏在心里，拍不出来；AI 视频里尤其不可靠 | 把内在变化落到一个可看见的选择或动作 |
| 一集里人际轴一次没动 | 关系戏缺位 | 补一场，或在既有的场里给关系一个真的选择（`story-framework.md` §2"季太目标化就补一集"） |

## 8. 集尾钩子

只从本集已发生的事产生，不另起谜题（单集四问已有此条）。三种形态：没说完的话或没回的消息；刚到达、还没被处理的信息；做出了选择、后果还没来。短集可以把钩子落在切点上。

## 9. 诊断：节拍单哪里不是戏

用户说"叙事感不对""心理状态不对""在交换信息"时，先查这张表，再回措辞。

| 症状 | 查哪一栏 | 改法 |
|---|---|---|
| 两人宣布关系、轮流解释 | 三问的"为什么是现在"答不出 | 给一个钟，或换到更难开口的时刻与在场者 |
| 一段信息交代，人物只是在听 | 三问的"要什么"答不出 | 合并、转述，或让信息进入一个当场的决定 |
| 场末和开场没有不同 | 开场值 → 结束值 | 删、合并，或写明余韵场的作用 |
| 两场转的是同一件事 | 相邻场的价值与方向 | 合并，或第二场转另一个价值 |
| 一拍里塞了两次转向 | 转折拍落不到一拍上 | 拆拍，让每一拍只做一件事 |
| 几拍下来只在办事 | 变化轴全是外部 | 让一拍落到人际轴 |
| 钩子是新谜题 | 集尾钩子 | 换成本集已发生之事的未完成部分 |
| 代价的场被删、被 hold | 支柱"第一次代价"是否落空 | 下一集开场先收代价（`story-framework.md` §2） |

## 10. 不做

- 不要求每场有反转、争吵、事故；安静的场要能说出作用。
- 不把三问写成台词：人物不说"我要什么"，人物做事。
- 不为了填满变化轴硬加内心戏。
- 不在戏化阶段写对白；对白等 `scene-work.md` §2 和 `dialogue.md`。
