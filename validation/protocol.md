# 验证方案（预先定义；全部标"待验证"直到真的跑过）

## 对照设计
- **A**：当前协作方式（直接要剧本 / 用现有 skill）。**B**：film-story。
- 同输入：同一份正典、台账、约束文件、同一句任务描述。同模型版本、接近时间、相同生成预算（记录轮数、输入输出字数、人工干预次数）。B 用了多轮就记多轮的成本，不隐藏。
- 每题各跑两次，保留全部输出（`validation/runs/<题号>/A1 A2 B1 B2`），不挑最好的展示。
- 复核样本：至少一段**未参与规则设计**的片段（另一部剧的一场，或同一部剧另一个未写过的节点），防止规则只对校准样本有效。

## 六项分别验证
| 项 | 怎么测 | 谁判 | 程序能查的 |
|---|---|---|---|
| 1 事实与约束遵守 | 对照台账 A、rules.md 与 constraints.md，逐条核：有没有改已拍事实、擅加人物、碰禁用词、违反本剧规则（已登记的例外不算） | AI 先查，用户复核 | 人名、禁用词、头部必填（`check_constraints.py`）；事实冲突需人读 |
| 2 读者理解 | 独立读者（没看过项目的人）读一段，答 `reader-probe.md` 的问题：人物选了什么、为什么、什么导致什么、关系前后变了什么 | 真人读者 ≥2 | 无 |
| 3 戏剧与对白质量 | 盲序配对：读者看不到 A/B 身份与顺序；按 `review-form.md` 写判断 + 文本证据 | 编剧（用户）+ 独立评阅 ≥1；AI 评审只提供问题线索，不计票 | 对白结构线索（`check_dialogue.py`） |
| 4 效率与控制 | 到可用稿的轮数、整场重写次数、同一错误重复次数（B 的场次表和逐场停是设计内的交付轮，单独记，不算返工；返工只算同一场被否后重写）；用户是否觉得失去控制（三问：方向是你定的吗、有没有被替你决定的事、有没有被迫批准的表） | 记录 + 用户自评 | 轮数、字数 |
| 5 候选实质差异 | 对每组候选填差异表（选择 / 代价 / 后果）；只换地点 / 措辞的记 0 | 用户或独立评阅 | 无 |
| 6 改稿命中 | 对每次改稿，对照用户指出的问题与改稿单的定位、前后对照：问题修到了没有；原本成立的亲密、幽默、信息、人物尊严有没有丢；有效的直接表达、重复、长段有没有被误删 | 用户 + 独立评阅 ≥1 | 无 |

## 判定
- B 在 1、2 不退步，3 或 4 有明确改善 → 继续用并进入下一集；
- 只在 4 改善、3 持平 → 保留台账与处境卡，缩节拍单；
- 3 退步 → 回到当前方式，保留台账（它独立于流程有用）。
- 6 不成立（改稿常修不到指出的问题，或常误删有效的写法）→ 改 `references/scene-work.md` 的改稿表与 `references/dialogue.md` 的反馈表，不影响上面几条。
- 不报分数；只报"成立 / 部分成立 / 不成立"和证据。
