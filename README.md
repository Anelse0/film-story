# film-story

人机协同的连续剧剧情开发与改稿。2026-10-18 起取代 film-creative；分镜与 Prompt 仍归 film-director。方法的公开出处见 `references/sources.md`，为什么是这几个模块、每个模块什么时候删见 `references/why.md`。

## 一部剧只有一份总表
`<项目>/story/<剧名>.md`，从 `templates/project.md` 复制：1 这部剧（一句话、论点、调性、怎么写 ≤ 6 句、题材手册）· 2 主要人物（要什么、怕什么、手里有什么、这一季的弧或计划、现在在哪、说话的做法）· 3 季线（季终落点、支柱、外部力量与相撞、每集一行）· 4 正典与悬线 · 5 制作参数（脚本读）· 6 不走的路 · 7 各集（要定的一件事、事件链、场次表、新事实、未纳入）· 版本记录。前四节是燃料，第 5 节是围栏。剧本正文在各集目录，头部三行（`templates/scene-header.md`）。0.9.0 的六份文件和各集卡按模板文末的对照并进来。

## 第一次用在一个项目上
1. 让 AI 从已拍 / 已采用的正典起草总表第 1、2、4、5 节，你逐格确认；第 1 节"怎么写"从你过去的纠正里挑 ≤ 6 句。
2. 聊季线：AI 一条消息问三到五个口味问题，然后 pitch 两到三条完整季线（季终落点、三根支柱、外部力量与计划、大悬线在哪集兑现、两位主角各失去什么），你反应，它当轮改；定了才写进第 3 节（`references/story-framework.md`）。
3. 之后每集：先聊——要定的一件事、两三条候选（每条要有跨集的主线事件、碰到至少两层、谁在推），你选定后写进第 7 节；再写场次表（三问与转向，成本只在这里算）；确认后一场一场写，每场交付后停，你采用或改定再写下一场；改稿先定位、按故障选幅度、写前后对照。候选不落档；被否的进第 6 节。

## 脚本
两个脚本都只读 `<!-- script-body:start -->` 与 `<!-- script-body:end -->` 之间的正文（没有标记的旧文件按全文读，并提示）；只报线索，退出码恒为 0。

```bash
python3 ~/.claude/skills/film-story/scripts/check_dialogue.py <场景.md>
```
```bash
python3 ~/.claude/skills/film-story/scripts/check_constraints.py <场景.md>
```

- 制作参数：不给 `--constraints` 时，从场景文件所在目录往上找 `story/constraints.md`（0.9.0 及更早），没有就找 `story/` 下带"制作参数"标题的总表（第 5 节；二、三级标题都认，可带编号）。
- 语言：`--lang auto|en|zh`，默认按全文多数台词判断，另一种语言的行算对照翻译。中文不支持的线索会在输出里写明。
- 时长：读第 5 节的英文语速、中文语速、单条生成上限；`--wps` / `--cps` 临时指定；都没有就只报词数或字数。估的是口播时长，不是成片时长。
- 说话人分画内 / 画外；同框人数要看动作描写，脚本不推算。
- 结构线索：等长对仗 / 排比、接住上一句的词反问（中英文都给）；复述确认也会被标，是否算问题看处境（`references/dialogue-patterns.md` §5）。
