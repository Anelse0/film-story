# 场景稿头部（置于项目自身剧本格式之前；键名不改，check_constraints.py 按键名检查）

字段按职业剧本工具组织（Final Draft 的场景标题、修订页眉、修订标记、备选台词；Scriptation 的跨版本批注），用户复核时不用重新对版本、找改动。写法照 SKILL.md §1"交付写法"：每个字段一两句，改动一条一句。

```
版本：vN · YYYY-MM-DD · 依据：节拍单 vX 第 n–m 拍
承接：上一场 / 上一集结束时的具体状态——人物所在位置、各自的知情情况、未回收的伏笔（≤ 2 句；上一场以用户采用或改定的版本为准）
本场改变了什么：一句话，写本场造成的变化（删去本场，观众会缺失哪项信息或情感）
新事实（提案）：本场首次出现、尚未录入台账的事实；无则写"无"

状态：探索稿 / 采用 vN（日期）

本版改动（相对 vN-1；本轮目标：一句话；依据："原话一句"；首版写"首版"，整场重写写"整场重写"）：
- 改：> 旧句 → > 新句
- 删：> 旧句
- 加：> 新句
- 动作 / 调度：一句话
历次（一版一行，最新在上；全文见版本历史）：
- vN-1 · 日期 · 改了什么 · "原话一句"

<!-- script-body:start -->
场 NN · 内 / 外、地点 · 日 / 夜 · 接 场 NN
（正文按项目自己的写法；本版改动、批注、备选台词都不写进正文）
<!-- script-body:end -->
```

## 正文写法

- 场景标题：场号 · 内外与地点 · 日夜（· 接场 NN）；地点用约束文件登记的名字。
- 动作写看得见、听得见的：人做了什么、看见什么、听见什么。不写"此处情绪升级"这类占位说明，不写替观众总结意义的句子。
- 角色名与台词按项目自己的格式。括注只在声源（电话里、画外）、重叠（抢话从哪个词切入）或读法确实需要时用，不写情绪标签。
- 正文从头到尾能直接读：备选、批注、改动记录都在标记之外，读的人不用拼接旧句和新句。

## 字段对照

| 字段 | 职业工具里的对应 | 规则 |
|---|---|---|
| 场号 | 锁定场号（locked scene numbers） | 场次表确认后不重编；插入的场加字母（02b）；删掉或 hold 的场号不复用 |
| 场景标题 | 场景标题行（slugline：内外、地点、时间） | 场号 · 内外与地点 · 日夜；地点用约束文件登记的名字 |
| 版本栏 | 修订页眉（修订版次与日期） | 每次交付升版：同一场的局部修改 v1.1、v1.2；整场重写 v2；写明依据的节拍单版本与拍号 |
| 本版改动 | 修订标记 / Track Changes / 版本对比 | 只写现行版：改 / 删 / 加，一条一句，引用旧句与新句，标题写本轮目标；写在正文之外，不在正文里打星号（正文要能直接读、直接交给导演层） |
| 历次 | 修订历史（revision history） | 升版时把上一版的本版改动压成一行移到这里：`vN · 日期 · 改了什么 · "原话一句"`；被否的版本也记 |
| 正文标记 | — | `<!-- script-body:start/end -->` 界定采用的正文：本 skill 的两个脚本只读标记之间，交接导演层时以标记内为准 |
| 批注块 | Scriptation 式批注：锚定场号 + 版本 + 台词，随修订迁移 | 格式见 SKILL.md §4；上一版的批注逐条标已改 / 沿用 / 作废 |
| 备选台词 | Final Draft 的备选台词（alternates） | 挂在批注里的原句下面；用户选定后只把一句写进正文 |
| 对应节拍 | Beat Board / Outline | 场次表记"对应节拍"；版本栏写依据的拍号 |
