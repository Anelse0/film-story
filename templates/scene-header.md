## 正文写法

- 场景标题：场号 · 内外与地点 · 日夜（· 接场 NN）；地点用总表第 5 节登记的名字。
- 动作写看得见、听得见的：人做了什么、看见什么、听见什么。不写"此处情绪升级"这类占位说明，不写替观众总结意义的句子。
- 角色名与台词按项目自己的格式。括注只在声源（电话里、画外）、重叠（抢话从哪个词切入）或读法确实需要时用，不写情绪标签。
- 正文从头到尾能直接读：备选、批注、版本记录都在标记之外，读的人不用拼接旧句和新句。

## 字段对照

| 字段 | 职业工具里的对应 | 规则 |
|---|---|---|
| 场号 | 锁定场号（locked scene numbers） | 场次表确认后不重编；插入的场加字母（02b）；删掉或 hold 的场号不复用 |
| 场景标题 | slugline | 场号 · 内外与地点 · 日夜；地点用总表第 5 节登记的名字 |
| 版本栏 | 修订页眉 | 每次交付升版：同一场的局部修改 v1.1、v1.2，整场重写 v2；状态（探索 / 采用）和依据（总表的集与场）写在同一行 |
| 本版改动 | 修订标记 / Track Changes | 不进文件：交付时在对话里列 改 / 删 / 加（旧句 → 新句），git diff 是正本 |
| 版本记录 | 修订历史 | 正文标记和批注块之后，一版一行：`vN · 日期 · 改了什么`；被否的版本也记；0.9.0 前叫"历次"、放在头部 |
| 正文标记 | — | `<!-- script-body:start/end -->` 界定采用的正文：两个脚本只读标记之间，交接导演层以标记内为准 |
| 批注块 | Scriptation 式批注 | 只在需要时写；格式见 SKILL.md §4；上一版的批注逐条标已改 / 沿用 / 作废 |
| 备选台词 | Final Draft 的 alternates | 挂在批注原句下；用户选定后只把一句写进正文 |
| 新事实 | — | 不在头部；写在总表第 7 节本集的"新事实"，采用后进第 4 节 |
