# 改稿单 · <场 / 集>（日期 · 探索稿 / 采用）

写法照 SKILL.md §1"交付写法"：前两行是结论，其余一条一行。

**问题在 __ 层**（措辞 / 台词 / 节拍 / 方向 / 处境），因为 __（依据：R# / 通用默认；违反规则 / 已登记的例外 / 规则之外）。意见说的是这部剧该怎么写 → 记进规则表"待定"。
**本轮目标**：一句话（同场景稿头部"本版改动"的标题）。

- **意见**：原话一句；哪部分是观察（"这里听不懂谁在说谎"），哪部分是解法之一（"加一句旁白"）。外部反馈另写来源：真实读稿 / 排练 / 导演现场 / 成片（谁、哪一次、对着哪个版本）；没发生的不写，模型分析标"模型分析"。
- **定位**：原稿里不成立的原句、动作或缺失的反应，一条一行。
- **幅度与范围**：措辞 / 交往方式 / 场内事件 / 前场（`references/scene-work.md` §3 的哪一行）；范围 = 意见指向的部分 + 直接受影响的上下句或上下拍。
- **改法**（解法不止一种且会改变人物或后续时，先列两三种，不改稿；每种一行）：〈改法名〉：改动 / 本场因此变成什么 / 对后续的影响。台词层的改法写成挂在原句下的备选台词，连着它改变的回应一起写。
- **改动**（同场景稿头部的本版改动；一条一句）：改 > 旧句 → > 新句 / 删 > 旧句 / 加 > 新句。
- **前后对照**（每处一行）：断在哪 → 新稿哪一句或哪个动作补上。另起一行写损失：原本成立的亲密、幽默、信息、人物尊严和本场作用有没有丢。只是更短、更含蓄或更激烈，不算改好。
- **连带影响**（一条一行）：后续场次（未写的只改场次表对应行，不预写）、台账中受影响的伏笔；根因在前场时写最小补写（哪一场、最少建立什么）。
- **保留项**（一条一行）：上一版中承载人物识别性、回应关系或吸引力的台词与动作 + 为什么留。
