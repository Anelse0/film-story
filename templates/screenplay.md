# 剧本文件：头部与正文（一集一个文件；头部键名不改，check_constraints.py 按键名检查）

字段按职业剧本工具组织（Final Draft 的场景标题、修订页眉、修订标记、备选台词；Scriptation 的跨版本批注），用户复核时不用重新对版本、找改动。写法照 SKILL.md §1"交付写法"：每个字段一两句，改动一条一句。正文是标准剧本格式的 Markdown（`references/screenplay-format.md`）。

````
# <剧名> · EPxx〈集名〉

版本：vN · YYYY-MM-DD · 依据：节拍单 vX
说明：印在扉页左下角的一两句（这一版是什么稿、还剩哪些占位符、页数怎么读）；可选，没有就删这一行
承接：上一集结束时的具体状态——人物所在位置、各自的知情情况、未回收的伏笔（≤ 2 句）
新事实（提案）：本集首次出现、尚未录入台账的事实，前面标场号（S04：__）；无则写"无"
页数：出整集 PDF 时脚本回填；可选，不出 PDF 就删这一行

状态：初稿 · 写到 S04 / 初稿 · 写完 / 重写 · 进行中 / 重写 · 结构已锁 / 精修 · 进行中 / 精修 · 有条件锁稿 / 精修 · 已采用（只留现在的那一个，日期跟在后面）。各场的状态记在节拍单的场次表
````

## 正文写法

元素、示例和约定见 `references/screenplay-format.md`；项目另有约定的（动作描写用哪种语言、要不要对照翻译、文件名）写在项目的 `story/README.md`。要点：

- 每场开头一行场标记 `<!-- S03 · 名字 -->`，场号和名字同节拍单。它在渲染后不显示，脚本靠它分场、按场合计台词量、按场取出。一场可以有几个场景标题。
- 场景标题是二级标题 `## INT. / EXT. 地点 - 时间`（中文稿写 `## 内 / 外 · 地点 · 时间`），不带场号，地点用约束文件登记的名字。
- 动作写看得见、听得见的：人做了什么、看见什么、听见什么。不写心理，不写"此处情绪升级"这类占位说明，不写替观众总结意义的句子，不写机位。
- 角色名加粗、全大写、单独一行，下一行紧跟台词。括注只写声源（`(V.O.)`、`(O.S.)`）、对谁说、从哪个词抢话，不写情绪。
- 留白（反应、不回答、一个动作做完）单独成段，前后空一行。
- 正文从头到尾能直接读：改动记录在头部，批注和备选在批注文件，读的人不用拼接旧句和新句。
- 还没写到的场不占位：写一场加一场，头部的状态写"初稿 · 写到 S__"。
- 扉页不另写：出 PDF 时取头部的一级标题、版本栏里的版本和日期、"说明"（`references/screenplay-format.md` §5）。

## 字段对照

| 字段 | 职业工具里的对应 | 规则 |
|---|---|---|
| 场号 | 锁定场号（locked scene numbers） | 写在场标记里；场次表确认后不重编；插入的场加字母（S02b）；删掉或 hold 的场号不复用 |
| 场景标题 | 场景标题行（slugline：内外、地点、时间） | 二级标题 `## INT. / EXT. 地点 - 时间`；地点用约束文件登记的名字 |
| 动作、角色名、括注、对白 | 标准剧本的元素（Action、Character、Parenthetical、Dialogue） | 写法见 `references/screenplay-format.md` §1；标准页和 PDF 由 `scripts/render_screenplay.py` 导出 |
| 状态 | — | 写成"阶段 · 状态"（SKILL.md §2）：初稿、重写各有进行中和完成两种，精修多一种有条件锁稿；"重写 · 结构已锁"之后才精修；"精修 · 有条件锁稿"是还差几项条件（写在精修简报里）；"精修 · 已采用"之后才交导演层，之前都是探索稿 |
| 版本栏 | 修订页眉（修订版次与日期）；扉页上的稿次 | 每次交付升一版（写完一场、改完一轮都算），写明依据的节拍单版本。各截用 ` · `（两边带空格）分开；"依据"之前、日期之前的部分照原样印在扉页上，要带稿次标签就写进去：`Draft v1.4 (Lock Candidate)`、`草稿 v1.4（定稿候选）`；最后一截带数字的当日期 |
| 一级标题、说明 | 扉页（Title Page） | 一级标题用 ` · ` 分成剧名和集名，扉页上各占一行；"说明"印在扉页左下角、日期上面 |
| 页数 | 页码 | 出整集 PDF 时脚本把页数回填到这一行（不含扉页；有对照翻译时写明含不含）；页码、跨页对白的 `(MORE)` / `(CONT'D)` 只在 PDF 上 |
| 本版改动 | 修订标记 / Track Changes / 版本对比 | 只写现行版：改 / 删 / 加，一条一句，前面标场号，引用旧句与新句，标题写本轮目标；写在正文之外，不在正文里打星号（正文要能直接读、直接交给导演层） |
| 历次 | 修订历史（revision history） | 升版时把上一版的本版改动压成一行移到这里：`vN · 日期 · 改了什么 · "原话一句"`；被否的版本也记 |
| 正文标记 | — | `<!-- script-body:start/end -->` 界定正文：本 skill 的脚本只读标记之间，交接导演层时以标记内为准 |
| 批注块 | Scriptation 式批注：锚定场号 + 版本 + 台词，随修订迁移 | 写在每集一个的批注文件里（剧本文件名加 `-notes`），按场分节；格式见 SKILL.md §4；上一版的批注逐条标已改 / 沿用 / 作废 |
| 备选台词 | Final Draft 的备选台词（alternates） | 挂在批注里的原句下面；用户选定后只把一句写进正文 |
| 对应节拍 | Beat Board / Outline | 场标记的场号对应节拍单"场次与节拍"里的那一节；版本栏写依据的节拍单版本 |

一场一个文件的旧稿（头部带"本场改变了什么"）照读，不为改成一集一个文件而改。
